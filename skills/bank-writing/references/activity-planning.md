## 适用

适用于商业银行各类营销宣传、客户回馈、主题宣讲、投融资对接、银政企合作、金融消保宣教、网点微沙龙、技能竞赛及行内大型会议等方案策划与落地撰写。

---

## 建议结构

一份完整严谨的银行活动策划方案通常包括：
**活动背景与目的—活动主题与宣传口号—目标客群与邀约规则—活动时间与场地动线—核心流程与环节设计—资源配置与费用预算—组织分工与行内协同—风险预案与消保合规审查—后期跟踪与效果评估**。
可按任务规模灵活剪裁，微型活动（如网点微沙龙）重点保留主题、流程、分工与合规提示；大型活动必须要素齐全。

---

## 编写要点

1. **目标可量化、可拆解**：
   - 区分定性目标（提升品牌影响力、增进客群粘性）与定量目标（意向客户转化数、新增AUM、新增授信储备金额）。
   - 目标必须切合实际，不编造夸大、无法落地的虚高指标。
2. **动线合理、注重客户体验**：
   - 考虑客户入场签到、宣讲聆听、茶歇互动、私密洽谈的物理动线设计，避免拥挤杂乱。
   - 关键环节设置留资触点，顺畅过渡到“客户经理一对一深度对接”。
3. **真实性与状态标注铁律**：
   - 用户未提供的具体时间、地点、场地、承办人员、预算金额及报批状态，一律不得写成已确定事实。
   - 用户要求策划或提出方案建议时，必须明确标注为“建议、拟议”安排（如“拟于X月X日举办”、“建议预算XX元”），并注明“具体以行内实际审批为准”。
   - 严禁将活动策划方案直接改写或描述为“已成功举办并取得显著成效”。

## 银行典型营销与策划活动实战指引

### 财富管理与私人银行高净值客群沙龙
- **定位**：聚焦中高端财富客户（个人金融资产在50万/600万以上），提升客群深度信任度与资产留存率。
- **主题切口**：宏观经济与大类资产配置策略、家庭财富保全与代际传承、子女教育与留学金融规划、红酒/高端茶道/国学文化品鉴等。
- **环节设计**：专业投顾主题宏观解读（30分钟）—互动问答与热点答疑（15分钟）—茶歇交流与定制化资产检视（30分钟）—客户经理一对一跟进促成。
- **体验细节**：控制单场人数（建议15—30人以内），确保私密性与一对一服务质量。

### 对公与政企银企对接推介会
- **定位**：搭建政银企合作桥梁，拓展园区重点企业、招商引资项目及核心产业链客户。
- **主题切口**：“产融协同、赋能实体”、“专精特新科创企业投融资对接”、“供应链金融专项服务方案推介”。
- **环节设计**：政府/园区领导政策宣讲—行领导领导致辞—银行综合金融服务方案与创新信贷产品推介—重点客户现场战略合作签约仪式—银企自由洽谈。

### 普惠小微与乡村振兴“千企万村”大走访
- **定位**：深入工业园区、专业批发市场、农贸商圈及重点乡镇，打通金融服务“最后一公里”。
- **打法机制**：网格化扫街、走访排查，开展“送金融政策上门、送专属信贷产品上门、送便捷结算工具上门”。
- **落地形态**：流动服务小分队现场办公、移动开卡、快速测额授信。

### 金融消保与反诈宣传进社区活动
- **定位**：普及金融常识，守护群众“钱袋子”，提升公众防骗识骗能力与消保满意度。
- **主题切口**：“守护养老钱、远离非法集资”、“警惕电信网络诈骗、筑牢账户安全防线”、“理性投资、远离不良校园贷与非法中介”。
- **形式创新**：发放通俗折页、播放真实案例警示短视频、有奖知识问答互动、现场一对一解答老年人手机银行操作疑问。

### 旺季开门红线上线下融合营销方案
- **打法**：线上通过手机银行App开展“签到有礼、做任务抽微信立减金、资产达标领权益”集客；线下依托营业网点阵地开展“微沙龙进店有惊喜、福字春联迎新春、答谢老客户”联动转化。

## 活动方案核心八要素全景指引

| 要素维度 | 核心内容与设计要点 |
| :--- | :--- |
| **1. 背景与目标** | 交代活动驱动动因（季节攻坚、客群破局），列出定量转化指标（如触达客群XX户、意向登记XX笔）与品牌影响目标。 |
| **2. 主题与口号** | 主题应响亮、聚焦、富有金融温度，口号押韵易记（如：“智富未来，陪伴成长”、“金融暖风，惠聚万家”）。 |
| **3. 客群与邀约** | 设定明确的邀约标准（如行内白名单客群、特定产品到期客户），明确邀约渠道（客户经理专属电话、企业微信邀约、短信推送）。 |
| **4. 时间与动线** | 明确建议时间（避开客户工作忙碌期，如周末上午或工作日下午），规划签到区、宣讲区、交流区、咨询室的物理动线。 |
| **5. 流程与环节** | 细化到分钟级别的执行时序表（如：09:00-09:30 签到破冰；09:30-10:15 专题讲座；10:15-11:00 一对一交流）。 |
| **6. 预算与物料** | 条目化列示场地费、搭建费、音响设备、宣传物料（展架、折页）、茶歇点心、随手礼品费用测算，标明〔待报批〕。 |
| **7. 分工与协同** | 明确总协调人、主持人、主讲嘉宾、签到接待、拍照宣传、消保审查员、现场秩序维护员与跟进客户经理职责。 |
| **8. 应急与评估** | 针对电力音响故障、恶劣天气、现场客流超限、客户现场抱怨等制定应急预案；制定活动后复盘评估问卷与成效追踪机制。 |

## 银行活动严格合规红线与消保审查

银行策划活动受金融监管严格规制，必须坚决杜绝以下违规隐患：

1. **坚决禁止变相高息揽储与利益输送**：
   - 严禁通过赠送超标大额实物礼品、购物卡、现金红包、微信返利等手段变相提高存款利率。
   - 赠品或伴手礼必须符合行内费用管理标准，价值适度，严禁承诺礼品与特定期限存款金额强行挂钩。
2. **严禁虚假营销宣传与违规夸大承诺**：
   - 宣传文案必须经行内消费者权益保护部门与合规部门事前审核，确保信息客观真实。
   - 涉及理财、代销基金、保险等非存款类金融产品，活动现场必须明确揭示“理财非存款、投资有风险”，严禁口头承诺保本保息或将预期业绩当成确定回报。
3. **严格保护客户个人金融信息安全**：
   - 现场签到簿、互动大屏、意向登记表严禁公开泄露客户完整手机号码、身份证号、银行卡号及账户资产余额等私密信息。
   - 客户留存的联系方式与意向信息必须遵循“最小必要原则”，严禁向任何第三方商业机构非法泄露或买卖客户资料。
4. **确保场地安全与维稳防线**：
   - 现场严格遵守消防安全要求，严禁超员聚集；备好医药急救箱，配备老年人防跌倒等现场看护措施。
