# 定向修改、多轮约束与素材整合

只做文本写作，先按主入口完成素材/权限自检；事实、数字口径、待核状态、敏感信息及用户修改范围仍受保护。参考里的示例与术语不是本轮事实、现行政策或审批结论；不得照搬示例数字、文号或客户信息，不用换词掩盖违规事实。默认在对话中交付，不运行生成脚本、不落盘中间稿；DOCX仅在已有明确授权后按主入口交接。引用不是递归加载要求。

## 修改任务

针对用户提供的现有文稿或素材进行定向再加工时，必须严格区分不同任务类型的边界与目标：

1. **润色**：
   - **核心定位**：在绝对忠实于原文事实、业务立场与核心数据的前提下，提升文稿表达品质。
   - **操作顺序**：先理顺逻辑脉络，消除段落间的语义断层；再精简冗词赘句，剔除无实质信息的套话；最后优化专业金融措辞、工整小标题与行文语调。
2. **压缩**：
   - **核心定位**：大幅精简篇幅，提炼最硬核的信息主干。
   - **操作要点**：剔除铺垫性空话、修饰性背景、重复列举的通用过程；坚决保留核心业务主体、时段、关键经营数据（增量/存量/比率）、核心风险揭示及明确的决策/结论。严禁为压减字数而悄悄删除前置假设、免责限定或待核事项。
3. **扩写**：
   - **核心定位**：将提纲、草稿或过于简略的素材丰富充实为条理严密的专业文稿。
   - **操作要点**：围绕素材中已有的事实逻辑，深入展开具体的实施机制、工作路径、协同机制与保障措施；**绝对禁止凭空捏造未经证实的经营业绩、信贷数据、审批结果或典型案例**。素材缺失细节时采用稳妥的逻辑推展或占位符标记。
4. **改写**：
   - **核心定位**：文种转换、受众切换或视角调整（如将基层经验总结改写为向上级行的请示报告，或将技术方案改写为通俗汇报）。
   - **操作要点**：重新设计篇章架构与语体风格，但基础事实与业务口径保持不变。

## 多轮编辑纪律

在多轮交互修改银行文稿时，必须严格遵守以下编辑纪律，确保修改过程受控可回溯：

1. **局部锁定原则**：
   - 严格按照用户指定的段落、章节或具体意见进行修改；对前序轮次中用户已确认满意的段落保持锁定，不得在后续润色或全文整合时无故自作主张重新组织。
   - 除非用户明确提出全局重构要求，严禁借局部修改而推翻全文既定结构。
2. **明确删除不回流**：
   - 用户在上一轮明确要求删除的文字、论据、案例或修饰，在后续生成新版本时绝对不得再次出现或变相恢复。
3. **联动变动最小化与显式告知**：
   - 当某一处事实或数据修改引发全篇其他段落的关联影响时（如：修正了存款期末余额，关联到存贷比、同业份额排名或息差分析），仅同步修正存在必然逻辑因果的关联内容，并在文后简短说明联动修改位置。
   - 若关联修改存在多种口径选择且无法自行推定，正文保留已有表述并标记待核确认，不擅自扩大修改范围。
4. **版本差异清晰交付**：
   - 用户要求成稿时交付修改后的完整通篇文本；用户要求查看修改细节时，条目化列出“修改位置—原表述—修改后表述—修改依据/理由”。

## 多份素材整合

### 素材整合五步法

面对来自不同部门、不同时期或不同维度的多份分散素材，必须按以下步骤推进整合：

1. **建立事实台账**：提炼素材中涉及的“时间节点、责任机构/部门、业务品种、核心指标数据、信息来源、当前推进状态”。
2. **聚类与去重**：将同一事件在不同报告中的重复描述合并归类，消除同一业务的机械拼接，避免把多次提及累计为多项成绩。
3. **识别矛盾冲突**：重点比对多份材料中在“统计口径、金额、时间、审批状态”上的细微差异。
4. **重构统一主线**：摆脱素材原有的汇报顺序，按照总行管理意图或文种逻辑重新搭建结构骨架（如按“业务板块”或按“量-价-险-构”重组）。
5. **统一文风与术语**：消除不同部门起草文稿间的语体风格差异，统一全篇专业金融术语、标题体例与层级格式。

### 来源冲突与口径差异处理规范

当多份素材出现数据或事实冲突时，必须遵守以下铁律：
- **严禁擅自裁定**：不得仅凭某一份材料“时间较新”、“由更高级别领导签发”或“篇幅较长”而自行决定采用某一方口径。
- **正文外差异比对**：在交付文稿的正文后单独列出差异比对表：
  *“【口径差异说明】：关于2026年三季度末小微贷款余额，素材A（普惠金融部汇报）记录为52.3亿元（含贴现），素材B（经营分析报告）记录为48.6亿元（不含贴现）。当前文稿暂采用〔待核口径〕，待确认后统一。”*
- **确认后全篇同步**：用户确认最终采用的口径后，一次性全篇同步更新所有相关计算指标与总结论，不留下半吊子矛盾。
