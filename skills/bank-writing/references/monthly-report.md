# 月报分析、比较与创建写作

## 任务与最小加载

将月报作为独立文种，而非经营分析报告的缩写。适用于全行、分支机构、业务条线、产品、客群、渠道、运营服务、数字应用及风险管理月报；不限定某一份范文。

- 需要从数据解读本月、比较月报、找亮点/问题/增长点，或从素材创建月报：使用本参考；短回答也保留证据限定。
- 仅摘要既有结论、定向润色、提取标题：按主入口的摘要或编辑路线，不重新分析。已确认的完整结论需要排成月报正文时，使用下方成稿结构，不强制追加经营分析或综合写作。
- 本参考足以处理普通月报。只有复杂贡献分解、息差/风险口径或银行专题确有需要，才追加 `<skill-root>/references/business-analysis.md#经营分析` 对应章节；不要默认加载所有参考。政策有效性和授信/审计结论另需相应专项依据。
- 只交付可复制文本，不写文件或自建计算脚本。输入缺失时继续可靠部分，缺什么就说明什么，不阻断整篇。用户只要回顾时不强行附增长方案。

## 一、接收素材与建立证据底稿

1. 确认报告月份、对象、受众、交付类型（解读/比较/新建/续写/审校）及重点；能由材料确定就不重复询问。缺关键条件才问，非关键部分先推进。
2. 核对已读覆盖：正文、表格、文本框、图表数据、注释及附录是否可见；由实际可用的文档 Skill 读取，不能因正文返回成功宣称图表已读。纯图片没有 OCR 时不猜数；图表缺缓存、缺工作簿或只有比例时保留缺口，不反推出未知绝对数。
3. 按需在对话上下文整理“指标—本期—基期—单位—范围/定义—来源位置—状态”，不要求另存文件。来源用实际页码、章节、表名或图名，工具未返回的页码/单元格不可编造；同一指标跨正文与图表重复出现只计一次。
4. 区分原始事实、可复核计算、待核冲突、原因假设及建议。正文与表格冲突先说明差异，不默认图表/新版本更权威；用户确认或明确修订说明才采用替代值，并联动摘要、表格和结论。
5. 少量明确数字列式核算。批量表格读取/计算按需由宿主定位现有 XLSX/ET 公开能力，交接授权输入、指标、分组、期间、单位与只读范围；收回来源、公式/舍入、缓存和部分结果状态。不导入私有实现，不把分析授权扩大为改表、导出或安装；不可用就继续已有可靠材料。

## 二、比较与指标校验

只填有依据的列，优先回应用户关心的指标。不要为了模板齐全编造历史、目标或同业数据。

| 比较类型 | 核验与表达 |
|---|---|
| 环比、同比、较年初 | 环比必须上月，同比必须上年同月；其他期间按实际日期命名。余额差是净变动，不是流入/发放；累计增速不等于单月增速。累计相减仅限同年度、可加、同口径且无未解释追溯调整。 |
| 变化额与增速 | 变化额=本期−基期；正基数增速=变化额/基期。零基数只报变化额，负基数优先说明亏损收窄/扩大，低基数同时列基数与增量。 |
| 比率和目标 | 3%到4%增加1个百分点，不是1%；比率仅在定义一致、覆盖完整且对象互斥或已去重时按分子分母汇总重算，不平均各机构比率。目标明确同口径且为正才算完成率，区分上限/下限与累计/单月；无月度计划不把日历进度当考核标准。 |
| 机构、产品与同业 | 核对时点、定义、区域、规模、渠道、客户构成及公开来源日期；只比可比项，不能由样本排名声称全行/同业排名。同业差距是核查线索，不证明潜力可达。 |
| 趋势与异常 | 两期只能说明变化，不称持续趋势；节假日、工作日、统计调整、活动、一次性大户分别核查。同季同比也不等于已消除季节性；未验证原因只列假设。 |

对数字化/渠道月报，明确 MAU 是月内去重活跃人数，DAU 是单日去重人数；日均 DAU 必须注明自然日还是工作日及实际覆盖天数，单日峰值不能代替日均；日活相加不是月活。DAU/MAU 仅在同人群、同活跃定义、同期间与已确认日均分子下解释使用黏性，不能把工作日日均与自然日日均直接对比。

触达→使用→有效使用→业务转化只在同一合资格人群及一致观察窗口下构成漏斗；否则分别描述，不硬算转化率。留存需明确同一批次与回访窗口，新增注册不等于新增活跃。人数、人次、会话、交易笔数、调用量及成功量分开；响应速度改善不直接等于客户满意或利润提升。

## 三、分析、结论与增长点

**最小分析顺序：本月表现 → 可比变化 → 贡献与拖累 → 质量及异常 → 按需提出机会。** 只有本月汇总也可写本月规模/结构，不能虚构增长与原因。

- 贡献选择互斥、完整、可加维度，先核对分项变化加总=总体变化；差额列残差，不摊平。产品与机构是不同解释维度，不交叉相加。正向增量和负向拖累都展示，不能只挑亮点。
- 净增为正且明细完整时可算分项变化/净增，贡献率允许负数或超过100%；净增为零不算贡献率，接近零突出正负抵消，净减时优先解释减少项和抵补项。不可加比率和重叠客群不套贡献公式。
- 结论按“判断＋关键证据＋范围/限定”写；原因需要过程证据，相关性只支持待验证解释。允许“规模改善，但收益/留存尚未证实”，不强行全面向好，不把建议写成已完成。
- 从增长项复制、拖累项修复、客群覆盖/转化缺口、产品结构、服务效率等寻找候选机会；高增速、低渗透或同业差距均不足以单独证明机会。区分已实现增长来源与未来增长点。
- 每个重要机会写“信号及来源 → 假设 → 成立条件/缺口 → 小范围验证动作 → 跟踪指标/周期 → 扩大或停止条件”。责任、时间、阈值没有材料依据时标为建议或待定；不擅自承诺资源与收益。
- 优先级综合证据、可触达空间、收益成本、风险及实施难度，资料不足不强排名。潜力估算必须给独立合资格基数、转化假设、客均贡献及区间，并标为情景，不叠加重叠客群，不把假设当预测。

| 月报对象 | 优先分析的组合 | 不可越过的边界 |
|---|---|---|
| 存款、零售财富 | 期末/日均、净增、结构、付息成本、客户集中与留存 | 期末高增不证明沉淀，内部产品迁移不算总资产新增 |
| 对公、普惠、贷款 | 余额/投放/收回、有效客户、审批转化、定价及资产质量 | 余额净增不等于投放，获批不等于提款；不作无依据授信结论 |
| 渠道、数字产品 | 活跃、覆盖、使用深度、漏斗、留存、成功率与单位成本 | 峰值不等于普遍提升，调用量不等于用户价值；不用其他月份的指标定义 |
| 网点、服务运营 | 业务量、办理时长、差错/投诉率、一次办结及资源投入 | 总投诉下降不证明投诉率下降，样本偏差与复杂业务构成需核对 |
| 风险、合规与管理 | 余额和比例、问题新增/存量/关闭、严重性及整改验证 | 比率下降可能来自分母增长；关闭事项不自动证明风险消除或合规达标 |

## 四、创建月报与多期续写

默认直接给可复制正文；用户只要分析就不强行写成完整报告。完整月报建议采用以下结构，按素材删减而非逐栏凑数：

1. **标题与范围：** 对象＋报告月份，必要时注明统计截止日与覆盖。
2. **本月摘要：** 2—4条最重要判断，按证据呈现改善、压力或持平，不强凑正负判断；每条有关键依据，无新证据不新增判断。
3. **核心指标与比较：** 本期、可比基期、变化额/适用增幅、目标差距及关键口径说明；可用对话表格，不导出文件。
4. **专题分析：** 按实际业务拆解贡献、拖累、结构、质量和异常，先结论再证据，避免逐表复述。
5. **问题与机会：** 事实问题、原因假设及待验证增长点分开；按用户要求提供。
6. **下月行动与验证：** 动作、建议责任方、观察周期、指标及扩大/停止条件；未经确认的安排标为建议。
7. **必要说明：** 仅列影响判断的缺口、口径变更和部分读取范围，不向业务读者暴露文件底层结构或工具回执。

延续上月版式时，只沿用结构/语气，不沿用旧月份数字、结论、目标完成状态或原因；已完成事项按本月证据更新。比较多份月报先统一指标字典，无法对齐的分开列；将追溯修订与真实变化区分。领导简报突出决策与证据，业务团队版保留拆解与验证动作，两版不能出现不同事实。

## 五、交付前验收

核对标题月份、正文/图表数字一致、基期、单位、分母、去重、覆盖、加总、百分比/百分点、正负变化及事实/假设/建议。结论须能回到实际来源；没有来源的数字删除或明确待补，不凭范文补齐。保留无法读取且会影响结论的内容说明，不能把漏读当零。

复核只交付用户需要的文本，无脚本、落盘底稿、虚构下载链接或归档动作；需要 DOCX 时按主入口明确授权交接。范文只迁移分析方法和写作结构，测试只用合成素材，不将用户业务材料纳入 Skill 或测试包。
