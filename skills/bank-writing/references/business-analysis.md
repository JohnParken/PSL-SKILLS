## 经营分析

本页用于非月报经营复盘、复杂贡献分解和业务专题；普通月报分析/成稿直接读 `<skill-root>/references/monthly-report.md`，只压缩已有结论走摘要，不因“找亮点”重复加载本页。客户沟通另见 `<skill-root>/references/customer-communication.md`。本页只交付文本，不自建计算脚本，不替代业务审批、政策核验或预测模型。

### 经营任务与最小分析路径

先核对范围与口径，再按所问指标说明表现、贡献/拖累、增长质量及需要验证的机会；不强制穷举指标或附下一步方案。只有汇总值就只说规模与结构，缺基期不算增速，缺明细不定来源，缺过程证据不定原因。分析后仅在确需成稿时追加月报、总结或讲话等对应文种，不能为凑框架补造事实。

### 数据口径与表格结果交接

1. **标明范围。** 确认期间、本月/年内累计、机构与层级、币种、单位、指标定义、来源及已读覆盖。少量文字数字保留原句或表行；表格结果保留文件、工作表、区域/行或提供方给出的来源定位，不虚构单元格地址。
2. **先做可比性核对。** 区分时点余额、期间发生额、日均和比率；核对机构调整、口径版本、缺失、重复、合计与明细混入、公式缓存及单位差异。同一指标只能在一致或明确调整后的范围比较；调整必须可追溯，不暗自换口径。明细与合计不符时展示差额和受影响范围，不把差额摊平。
3. **少量数字列式核算；批量数据交给现有能力。** 用户提供的明确小表可逐项算并核对加总。需从 XLSX/XLSM、CSV/TSV 读取或批量统计时，由宿主定位实际可用的 xlsx 主入口；ET/ETT 由宿主定位 et。只使用提供方当前公开入口支持的读取/分析能力，先按其自检与契约确认格式、能力、输入及权限，不猜相邻安装目录、不导入私有实现、不复制计算逻辑。此为按需交接，不是 bank-writing 的强制安装依赖或新建自动调用接口。
4. **交接要保留授权和缺口。** 请求中带上用户允许的输入与只读范围、待分析指标、分组、期间、单位和比较要求；不把分析授权扩成改表、导出、转换或安装授权。取回结果值、计算/舍入口径、来源范围、状态、缓存、缺失、partial 与截断诊断，按提供方实际契约判读，不假设统一 JSON 字段。需要机器接口时先核对其能力及兼容版本，不用 Skill 时间戳代替接口版本。
5. **失败与部分结果。** 工具缺失、不兼容或读取失败时，不自写脚本或换工具绕过边界；只继续已有可靠素材支持的部分。局部结果可以说明局部情况，不能推成全行总量、全量排名或完整贡献；缓存未核验和遗漏须随结论保留，缺值不填零。宿主截断无法补齐时停止依赖缺失内容的结论，读取故障按 `<skill-root>/references/source-access.md`。

### 当月表现与比较基准

先给关键指标的“本期值—比较期值—变动额—适用增幅—目标差距”，只列有数据的列；区分“金额增量最大”“增速最快”“计划进度领先”，不能互相替代。

- **期间。** 环比明确与上一个月比，同比与上年同月比，较年初另列；缺期不拿最近可用月份冒充环比。累计发生额只有在同年度、同口径、可加且无未解释追溯调整时，才可用本月累计减上月累计得到本月发生额。余额两期相减是净变动，不是本月流入、销售额或贷款发放额；不能把累计增速当单月增速。
- **公式。** 变动额 = 本期值 − 基期值；基期为正时，增幅 = 变动额 / 基期值 × 100%。基期为零时只给变动额并说明增幅不适用；负基数优先说明亏损收窄/扩大等绝对变化，不据机械百分比判断好坏。低基数高增速同时列基数与增量，不以增速单独评优。
- **比率。** 3%升至4%是上升1个百分点（100个基点），相对增幅约33.33%；不写成“上升1%”。跨机构比率需同口径分子分母汇总后重算，不能简单相加或平均。NIM、付息率等核对期间、平均余额与年化约定，不把月度未年化值直接比年度值。
- **计划。** 同口径正目标可算实际/目标及差额，注明是余额、增量还是累计发生额目标；上限型与下限型指标分别解释。未给目标、目标为零/负或考核规则不明时不套完成率。按日历时间折算只能标作粗略参照，不能替代正式月度计划或季节性进度。
- **趋势。** 同比有助于观察同季节比较，但不证明季节因素已消除；两个月不够认定持续趋势。利率、政策、营销和客户行为只在本轮证据支持时作为解释，否则列待验证假设。

### 增长贡献与负向拖累

先选一个可加且互斥、完整的拆解维度，如产品、机构或客群；不同维度各自解释同一总量，不能把“产品贡献”和“机构贡献”相加。合计与下级、重叠客群不重复计入；分类迁移单列，不把内部迁移当全行新增。

1. 各分项变动 Δᵢ = 本期值ᵢ − 基期值ᵢ；总净变动 Δ = 本期总量 − 基期总量。核对 ΣΔᵢ = Δ；记录尾差、遗漏或无法解释的残差，不强行归零。比率和不可加指标不套此公式，改用对应分子分母及结构解释。
2. 同时给正向增量合计 P = Σmax(Δᵢ,0) 和负向拖累合计 N = Σmin(Δᵢ,0)，满足 P + N = Δ。分别按增量和拖累绝对额识别主要分项，不只展示增长项。
3. Δ为正且分项覆盖完整时，可给净增量贡献率 Δᵢ/Δ；它可能为负或超过100%，不要裁到0—100%。Δ为零时贡献率不适用；Δ为负时优先报告减少项及抵补项的金额，不把正贡献率误称增长贡献。净额接近零且正负抵消明显时，突出P、N，不用巨大的贡献率制造重要性。
4. 如另列“正向增量占比”Δᵢ/P或“拖累占比”|Δᵢ|/|N|，分别只用于正项或负项并写清分母；不能与净增量贡献率混称。零分母不计算。
5. 只有完整、可比的稳定对象明细和业务状态证据，才进一步分新拓、存量提升、流失/流出、迁移等来源。某对象只出现在一期不自动证明新开户或流失，两期余额不能还原期间资金流；仅有汇总表时停留在产品/机构等已有维度。

**虚构算例（只演示计算）：** 上月A产品600万元、B产品400万元，本月分别750、350万元，覆盖全部且互斥。总量1000→1100，净增100、环比10%；A增加150，B减少50，正向增量150、拖累−50；净增量贡献率分别150%、−50%，合计100%。A是本月主要拉动项，B存在拖累；尚不能断言A可持续、B因服务下降流失或新增来自营销活动。

### 增长质量

在贡献事实之后，按已有数据选择下列维度；每项写“证据—能支持的判断—尚缺什么”。没有证据不默认质量良好，也不预设统一评分权重或监管阈值。

| 维度 | 应核对的证据 | 结论边界 |
|---|---|---|
| 持续性与资金沉淀 | 多期趋势、日均、期末与期后变化、一次性大额事项 | 期末高于日均只是差异信号；无期后与交易证据不能断言冲量或资金搬家 |
| 收益与成本 | 同期收入、利息支出、可比平均余额、费用与定价 | 规模增长不等于利润增长；名义利率均值不等于实际资金成本 |
| 结构与集中度 | 活期/定期、产品/客群结构，完整总体内Top客户或机构占比 | 增量集中说明依赖程度，不单凭集中认定风险超限；局部样本不推全行集中度 |
| 客群与转化 | 可比客户数、有效/活跃口径、触达与转化漏斗、留存及复购 | 新增数不等于有效客户；转化率需同一合资格人群与一致观察窗口 |
| 风险与资源效率 | 资产质量、成本、人员/渠道投入、资本占用等适用数据 | 不跨不同规模与口径直接评优，不据单个指标作授信或合规结论 |

总体评价允许“规模改善，但持续性尚未证实”“增量集中且成本上升”等有条件结论，不强行归为好/坏。只见余额和增速时，明确增长质量证据不足，列最影响判断的补充数据即可。

### 增长机会与行动验证

**已实现的增长来源不等于未来增长机会。** 机会来自具体信号与可验证空间，不机械把增长最快的项目排第一。按用户需要筛选以下方向，不要求每类凑满：

- **复制已有有效做法：** 找到可重复、收益/成本可接受的增长来源，再核对其他机构或客群的适用条件；一次性大户或低基数增长不直接推广。
- **修复拖累与流失：** 对负向分项先核对到期、迁移、统计调整和经营变化；原因未明时先提出调查或小范围验证，不直接归责人员或服务。
- **挖掘转化与结构空间：** 有合资格客群、触达/转化、产品覆盖或同口径对标数据时，定位具体环节；低渗透不自动代表需求，同行差距不自动证明可达。

每个重要机会保留这条证据链，篇幅短时可合并表述：

**数据信号及来源 → 机会假设 → 成立条件/缺口 → 建议动作 → 跟踪指标与观察周期。** 责任主体、资源与时间没有授权或材料依据时标为建议/待定，不写成已部署。

优先级结合证据可信度、可触达空间、收益成本、风险和实施难度定性说明；无足够数据就不强排名。若估算潜力，必须给出独立、未重复计入的合资格基数、转化假设、客均贡献及区间，标明情景估算而非预测/承诺；缺这些条件不编造“预计新增XX万元”。检验指标应覆盖净增/留存/日均及适用的成本风险指标，不只看触达量。

### 结论证据与输出验收

- **事实**引用提供的值及口径；**计算结果**保留基数、公式与舍入说明；**原因解释**需要业务记录等证据；仅有相关性时标为**待验证假设**；**建议**与已执行动作分开。结论出处可集中放在简短表中，不必每句重复。
- 通常先给当月主要判断，再列主要贡献与拖累、质量及用户需要的机会，最后列最关键缺口。用户只要短结论时压缩表达，不删掉影响结论的范围或待核限定；不展示内部推理过程。
- 交付前核对数字与来源、分项加总、比较基期、百分比/百分点、事实与假设，以及是否遗漏负向变化。只读部分数据、未验证缓存、缺基期或目标等限制随结果交付，不用“全面向好”掩盖未知。

### 核心分析框架与归因模型

银行经营分析应以价值创造与资本约束为核心，常用分析模型包括：

1. **“量-价-险-构”四维综合归因模型**：
   - **量（规模效应）**：分析资产负债总量的增长速度、计划完成率及在当地同业市场的份额变动。
   - **价（收益与成本）**：拆解生息资产收益率、付息负债成本率以及净息差（NIM）、净利差（NIS）的边际变动趋势。
   - **险（信用与风险成本）**：评估资产质量迁徙、信贷资产拨备计提对营业利润的侵蚀程度。
   - **构（结构优化度）**：剖析存贷款结构（零售占比 vs 对公占比）、活期与定期期限匹配度、中间业务收入占比。

2. **息差收窄与变动归因分析**：
   - 资产端：新发放贷款定价下滑程度、LPR重定价滞后效应、贴现及低收益资产占比。
   - 负债端：存款定期化趋势、协议存款与大额存单占比、主动负债（同业存单/发债）资金成本。
   - 归因核验：外部市场因素与内部结构因素分别寻找本轮依据；未提供市场、定价或结构数据时仅作为待验证方向，不预设原因。

3. **穿透分析与口径对比**：
   - **时点 vs 日均**：时点反映特定日期余额，日均反映期间平均水平；仅在有完整日度及期后数据时描述“季末冲高、月初回落”的幅度，不从时点差异直接推断冲量。
   - **增量 vs 存量**：存量展示基本盘，增量揭示发展动能；重点分析新发放贷款与新增客户资产的投向。
   - **同比 vs 环比**：按上方比较基准核对季节、基数与期间差异，不将同比视为季节调整模型，也不把单期变化直接外推成趋势。

### 银行核心指标体系与统计口径

写作与审校时核对以下指标的专业口径与勾稽关系。下表是提示，不替代本行指标字典；涉及年化、平均余额、资本成本及监管适用范围时补齐实际定义，缺依据不判断达标。月报只用有关指标，不逐项套表。

| 指标维度 | 核心指标名称 | 关键口径与勾稽要求 | 写作表达要点 |
| :--- | :--- | :--- | :--- |
| **规模与流动性** | AUM（管理个人金融资产） | 按本行指标字典确认存款、理财、基金、保险等纳入范围和计量方式，不预设所有项目均纳入 | 明确“存款+非存”的构成比例，内部转化不等于总AUM新增 |
| | 存贷款余额与日均 | 分清“各项存款/各项贷款”口径，区分本外币合计与人民币口径 | 杜绝将时点余额增量等同于资金沉淀能力 |
| | 存贷比（LDR）与流动性覆盖率（LCR） | 贷款余额/存款余额；合格优质流动性资产/未来30日现金净流出量 | 说明是否在流动性监管红线及风险容忍度以内 |
| **盈利与息差** | 净息差（NIM）与净利差（NIS） | NIM = 净利息收入 / 平均生息资产；NIS = 生息资产平均收益率 - 付息负债平均成本率 | 精准反映资产负债定价能力，单位通常为百分比或基点（bps） |
| | 综合付息率与活期沉淀率 | 付息支出 / 平均计息负债；活期存款日均 / 各项存款日均 | 强调“低成本活期结算资金沉淀”对压降负债成本的贡献 |
| | 非息收入占比与成本收入比（CIR） | （手续费及佣金净收入 + 其他非息） / 营业收入；业务及管理费 / 营业收入 | 体现轻资本转型成效与经营集约化水平 |
| | RAROC 与 EVA | 风险调整资本回报率；经济增加值 = 净利润 - 资本占用成本 | 衡量扣除风险成本与资本占用后的真实价值创造 |
| **资产质量与风险** | 不良贷款率（NPL）与关注率 | 不良贷款余额（次级+可疑+损失）/ 各项贷款余额；关注类贷款占比 | 重点说明不良贷款“一升一降”还是“双降” |
| | 逾期不良剪刀差 | 先确认是逾期90天以上贷款余额与不良贷款余额的比值还是差额，不混用单位 | 比值差异仅是核查信号，不能单凭大于/小于100%判定分类合规或审慎 |
| | 拨备覆盖率与拨贷比 | 贷款损失准备 / 不良贷款余额；贷款损失准备 / 各项贷款余额 | 反映风险抵补能力与利润平滑缓冲垫厚度 |

### 经营分析报告标准结构与写作范式

规范的银行经营分析报告通常遵循四段式逻辑：

1. **整体运行大盘（总量与态势）**：
   - 概述期内主要经营指标完成情况（资产规模、存贷款、营业收入、账面利润）。
   - 对照已提供的月度计划或适用年度目标，时间进度仅作注明假设的参照；同业或系统排名需可比、完整数据。
   - 亮出核心亮点（如：“规模稳步扩增，息差降幅趋缓，资产质量保持稳健”）。

2. **分条线/分产品经营特征剖析**：
   - **对公业务**：聚焦重点产业集群贷款投放、制造业与绿色信贷占比、战略核心客户开拓、供应链金融落地情况。
   - **零售业务**：聚焦零售AUM增量构成、按揭与消费贷投放边际变化、代发工资客群转化率、手机银行活跃度（MAU）。
   - **普惠金融**：按本轮已确认适用的考核要求分析达成情况、首贷户拓展与服务覆盖，不把历史口号当作当前考核规则。
   - **金融市场与资管**：投资收益、同业流动性融通、代客理财规模变动。

3. **突出痛点与深度归因（直面矛盾）**：
   - 不隐瞒差距，直击弱项（如：高成本协议存款占比偏高、中收支柱产品增长乏力、新增不良个案冒头）。
   - 列出并核验原因：需求、营销、产品机制、审批流程等只作候选解释，分别标明支持证据与待核项；不能由结果直接归责。

4. **靶向举措与下一步经营策略**：
   - 举措具备操作性、针对性，牵头部门、资源、周期与验收指标按素材或明确标注的建议给出，不补造已定安排。
   - 杜绝空喊口号，聚焦“抓沉淀、拓客群、优定价、控风险、强考核”。

### 典型痛点归因与写作改写示例

以下均为虚构教学素材，不能迁移到用户月报。

- **原始素材**：截至三季度末，各项存款余额1200亿元，较年初增加50亿元；对公增加30亿元，零售增加20亿元，二者互斥且覆盖全量。同期可比、同年化口径存款付息率2.15%，同比上升5bps。未给年度目标、产品结构、日均或原因证据。
- **可支持的改写**：“截至三季度末，各项存款较年初净增50亿元，其中对公、零售分别贡献30亿元和20亿元，占净增量的60%和40%，对公是主要拉动项。存款付息率同比上升5个基点至2.15%，规模扩张同时需关注成本变化；尚缺产品结构、日均和利息支出等信息，不能确定成本上升原因及利润影响。建议先核对成本上升集中在哪些产品及客户，再评估优化空间。”
- **不能补入**：目标完成75%、定期贡献68%、活期占比下降2.3个百分点，或“客户投资意愿偏弱导致增长”等原始素材未支持的数值与原因。这里是较年初累计净增，不能改写成本月净增；建议不是已实施动作。

## 业务专题

业务专题聚焦特定业务领域、重大改革试点、特定风险处置或客群攻坚，强调问题导向、机制剖析与可落地的行动路线。

### 重点业务条线专题撰写要点

1. **普惠金融与小微攻坚专题**：
   - 围绕“敢贷、愿贷、能贷、会贷”长效机制展开。
   - 梳理首贷户拓展成本、线上小微产品授信通过率、批量授信园区场景开拓。
   - 重点说明尽职免责制度落地情况，消除基层业务人员“惜贷、惧贷”心理。

2. **财富管理与零售大财富专题**：
   - 重点剖析客群分层运营体系（大众客户、财富客户、私行客户的流转转化率）。
   - 分析产品代销能力与投顾配置能力，剖析理财净值化转型背景下客户风险偏好迁移。
   - 对客户流失与资金变动核对完整范围和过程证据；“重销售、轻陪伴”只能在有支持材料时作为原因，不预设归因。

3. **信贷资产质量管控专题**：
   - 开展大额授信敞口排查、重点行业（如房地产、地方融资平台）违约风险预警。
   - 针对关注类贷款迁徙轨迹、逾期天数分布进行穿透，详细列示清收处置、核销与重组方案。

### 业务痛点下钻与闭环举措

撰写业务专题举措时，必须形成“痛点—原因—动作—责任—目标”闭环：
- **动作精准**：严禁使用“进一步抓好”、“持续加强”等无动作内容的空话，替换为具体动作（如“实施百日大走访”、“建立白名单机制”、“推出差异化定价授权”）。
- **要素完整**：标明涉及的主体、实施步骤、时间进度及预期达成的量化效果（仅在素材支持或用户授权建议时给出）。
