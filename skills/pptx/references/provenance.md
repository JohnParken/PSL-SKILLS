## 改造基线

SVG 到 DrawingML 的转换逻辑及部分形状数据源自 JohnParken/ppt-master 固定基线。
来源 URL：https://github.com/JohnParken/ppt-master/tree/5e8856be0da8e6bc85c4aa28acc614478f7b7137。
当前固定基线为 v6.8.0；已从原 v6.5.0 基线 `c951bf4a3a4af7cbc2382447f3d2e7719b292bd2` 逐文件迁移采用的转换子集。
此处记录来源，不要求运行时联网下载，也不把上游完整产品的能力视为本技能能力。
保留的转换模块位于 转换实现（`<skill-root>/scripts/_engine/`），新入口与受限的输入、组包、读取、验证逻辑位于 核心模块（`<skill-root>/scripts/pptx_core/`）。

本版保留受限 SVG 创建原生 PPTX、JSON 配置、纯文本备注、PNG/JPEG 及经测试的原生对象路径。
没有移植原项目的 YAML 工作流、角色提示词编排、模板管理、任意原生 PPTX 编辑、外部字体塑形、图片重编码、浏览器或办公软件渲染等能力。
运行只使用 Python 标准库；不要通过内置 Pillow、python-pptx 等第三方 Python 库的源码来规避该约束。由上游项目改造的纯标准库模块、静态数据资源与许可证均随此 Skill 分发。
没有复制其他 PSL 业务 Skill 的实现。公共归档与清理通过主入口规定的明确交接使用，不依赖猜测的安装布局。

## v6.8.0 迁移范围

采用的文件按两端完整 Git tree 与 blob 对照，新增依赖按实际导入追踪；不依赖可能截断的 GitHub compare 文件列表。

| 范围 | 本次采用与适配 |
| --- | --- |
| 文字与字体 | 同步字宽、重音字符与 Unicode 空格处理；增加随包字体度量和首行基线计算；保留标准库图片实现与内存 SVG 入口 |
| 文字拆行 | 同步身份、隐藏状态与链接内容保留；继续仅保留内存处理函数，移除上游命令行与文件工作流 |
| 原生图表 | 同步样式、语言、主题字体槽和布局修正；提取 `PackagePartRegistry` 内存部分，并在整份演示文稿内共享 |
| 表格与公式 | 同步合并覆盖格样式和原生公式备用显示；读取器只读取一条有效 MCE 分支，仍检查所有分支的结构 |
| 静态数据 | 原样同步字体数据及预设形状说明；几何定义与形状枚举未变，原校验和继续生效 |

保留的本地适配包括：Pillow 替代的 PNG/JPEG 检查与原字节嵌入、仅标准库的工作簿生成、`svg_text` 内存输入、禁用图片优化，以及精简的包入口、角色标记、动画分组和本地引用辅助函数。
本轮本地扩展位于核心模块：增加原生内容读回、源输入比对、MCE 语义处理和完整文件发布，不更换 v6.8.0 转换子集，也不引入第三方运行依赖。
表格预期使用语义输入的规范化结构，公式预期复用有限 LaTeX 编译器；独立预期测试另核对实际网格、合并区域、分子/分母等结构，避免将自比对误称完整正确性证明。
`theme_fonts` 不包含原项目按页面目录推断字体的工作流；包名注册不包含磁盘包发现或读取。上游的 `chart_patch.py` 不在本技能导入依赖中，不随包引入。
未迁移浏览器设计审查、PDF/网页等来源转换、图片生成 API、已有 PPTX/模板导入与回填、完整动画、音频或视频流程。导入专用的 opaque OOXML、外部原生载体与原始形状属性继续拒绝。
维护文件清单与来源 blob 记录保存在目标仓库根目录的 `tests/pptx/upstream_manifest.json`，不属于独立 Skill 的运行资源。
