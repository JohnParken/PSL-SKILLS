# 工具调用与结果读取

路径占位符说明：`<skill-root>` 是 XLSX Skill 根目录的文档占位符，不是实际目录或 Shell 变量。取得宿主本次实际读取 XLSX 主入口 `SKILL.md` 的真实 `file_path`，若为相对路径，先按该次读取时宿主已确认的基准目录解析为绝对路径，再去掉末尾文件名；所得目录才是 `<skill-root>`，不是当前参考文档所在目录。读取资源或执行命令前，将路径中的 `<skill-root>` 整体替换为该真实目录，保留其后的资源路径；命令中将替换后的完整路径作为一个参数正确引用，嵌入 execute 字符串时按其语法转义。不要将占位符原样交给文件工具或执行器，不按当前工作目录、其他会话路径、环境变量或宿主掩码猜测。无法取得主入口的真实读取路径时，停止依赖操作并报告无法定位。

仅在工具调用或回传异常时读取。正常任务先遵循主入口（`<skill-root>/SKILL.md#执行环境约束与首步自检`）。本页根据用户历史故障摘要定义规避规则，不表示真实宿主已完成修复。

| 故障 | 执行规则 |
|---|---|
| execute空参数或command缺失 | 以实际工具schema为准；要求command时提交完整非空字符串，不能发送空对象、规格对象或仅代码块。确认未调度后最多修正一次。参数校验失败不等于Python已启动。 |
| 同一call_id重复错误 | 按一次调用处理，不据重复注入自动重发。宿主以会话/响应、call_id与尝试标识去重，只注入一次同类校验反馈；真实新调用使用新标识，不按错误文本合并不同尝试。 |
| heredoc JSON错误 | 简单规格可直接写JSON，复杂规格必须用Python构造并序列化，见`<skill-root>/references/complex-json.md`，再编码工具参数；quoted heredoc不检查JSON。依据行列修正逗号、冒号、字符串及括号，内容没有改正不得原样重试。JSON语法与XLSX业务规格分别校验；不照搬DOCX的blocks字段。 |
| /tmp只读 | 任务临时配置及清单只创建于宿主确认的`./`并预先登记；标准runner自动管理配置。不使用系统临时根、切换目录或改TMPDIR规避；任务目录不可写时停止。 |
| Command failed、退出3或Directory not empty | 先读取完整stdout JSON、stderr及退出码，分别核对业务status、delivery与cleanup。业务成功而清理未完成时退出3，业务失败/部分计算保留原非零码。保留已写出的输出但不冒称完整成功，不重算、不递归删除未知目录。新版配置runner为平铺文件，目录残留需核对真实版本和原清单。 |
| /large_tool_results/可由read_file读取但Shell不可见 | 它是宿主结果引用，不是任务路径。必须使用`read_file`工具，按其真实schema提交宿主返回的完整结果路径，需要时分段读取；不交给Python、cat、cp，不猜共享挂载。需计算时由宿主明确桥接至`./`并验证数据完整；缺少桥接则说明限制。 |

每次调用必须回传stdout、stderr、真实退出码和调用标识；非零退出也不能丢弃JSON。未启动标记not_started，超时/强杀标记真实状态，不伪造退出码。截断结果注明范围和长度，不能把截断或分段JSON当完整数据。敏感正文、密钥及内部归档路径不向最终用户转贴。

对工具参数修正与业务任务重试分别计数。失败清理完成后如需再次生成，使用已修正的输入建立新任务；状态未知先核实，不以重发试探是否执行。清理受阻继续依据原清单和确切残留处理，不认领历史文件。详见交付生命周期（`<skill-root>/references/delivery-lifecycle.md`）。

宿主仍需实现参数完成后再调度、schema校验、按调用去重、两个输出通道回传和带访问能力的结果引用。Skill说明不能使两个文件系统自动共享；真实模型空参数率、重复调度率、跨工具访问及结果回传需在目标宿主验收。

若`read_file`不可用或读取失败，报告具体缺口并停止依赖该结果的操作；不得改用execute、Python或Shell读取`/large_tool_results/`，也不得猜测替代路径。工具参数遵循实际schema，不虚构参数名。
