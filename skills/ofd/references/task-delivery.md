路径占位符说明：`<skill-root>` 是 OFD Skill 根目录的文档占位符，不是实际目录或 Shell 变量。取得宿主本次实际读取 OFD 主入口 `SKILL.md` 的真实 `file_path`，若为相对路径，先按该次读取时宿主已确认的基准目录解析为绝对路径，再去掉末尾文件名；所得目录才是 `<skill-root>`，不是当前参考文档所在目录。读取资源或执行命令前，将路径中的 `<skill-root>` 整体替换为该真实目录，保留其后的资源路径；命令中将替换后的完整路径作为一个参数正确引用，嵌入 execute 字符串时按其语法转义。不要将占位符原样交给文件工具或执行器，不按当前工作目录、其他会话路径、环境变量或宿主掩码猜测。无法取得主入口的真实读取路径时，停止依赖操作并报告无法定位。

仅当用户明确要求结果文件时加载；普通 stdout 读取不加载。先按主入口自检；保存前用独占新探针实际写入、读回并清理，仅清理本次探针。宿主保存到任务 ./ 顶层尚不存在的 JSON 裸文件名，不覆盖已有文件，不用 Shell 重定向。

## 最终交付与读取中间结果

纯读取 stdout、模型分析用 JSON 与调试结果不自动归档。只有用户明确要求交付的文件才列入最终清单；保留输入原件，验收后由本包统一归档入口处理。每次使用宿主当次最新 questionId，缺失报告失败并保留主文件；归档目录及子目录不放临时文件。成功须完整非空清单全部核验通过，才提示“🎉 文件归档成功，请到云空间查看。 ☁️✨”。不复用历史回执，不声称已验证云端上传。

验收用户明确要求的结果文件后，用宿主 execute 提交完整命令 `"<skill-root>/scripts/.venv/bin/python" -I -S -B "<skill-root>/scripts/archive_delivery.py" 读取结果.json --protect-input 用户原件.ofd`，参数应替换为本轮实际文件名。批次状态 success/partial/failed/not_required，归档 CLI 分别退出 0/3/1/0，参数错误退出 2；单项 copied/already_archived/failed。仅分析用 JSON 不执行归档。

最终交付清单只包含本轮已验收且用户要求保存的结果；全部指定页和游标应读取完毕，缺页或 partial 必须随文件说明，不把单页 JSON 冒充全文。宿主保存后核对实际文件内容及来源，再执行归档；保存文件本身不会触发本技能归档。归档失败保留主文件并仅重试归档，未调用归档属于待交接，不是 not_required。没有文件交付需求的 stdout/分析中间结果才无需归档。OFD 创建和编辑服务仍不开放。
