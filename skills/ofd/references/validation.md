# 来源与验证记录

## 规范身份与实现依据

目标规范是 **GB/T 33190-2016《电子文件存储与交换格式 版式文档》正式版**，不以网上草案代替。以下是可追溯的公开来源：

- 国家密码管理局正式介绍 (`https://www.oscca.gov.cn/sca/ztpd/2017-04/19/content_1012652.shtml`)：2017-04-19，来源为国家电子文件管理部际联席会议办公室，确认标准的范围。
- 国家标准全文公开系统 (`https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=3AF6682D939116B6F5EED53D01A9DB5D`)：确认标准号、2016-10-13 发布、2017-05-01 实施及正式发布单位。
- 江苏档案部门公开的正式标准 PDF (`https://www.dajs.gov.cn/attach/0/88a7620d9d3f4e13b2baa52ab3487854.pdf`)：135 页，公开索引确认封面标准号及发布日期。没有将 PDF 或草案复制入包。

**证据边界：**已确认正式规范身份和公开附件，但没有完成正式全文所有字段的逐条核对。当前字段处理为待其余正式条款与真实样本进一步验收的有限实现，不能称为 GB/T 33190 全面符合性实现。已按独立查看的正式扫描条文核对：§6.2 单一 OFD.xml、§7.1 命名空间、§7.3 ST_Loc 点段与包根、§7.6 显式页序、§7.7 模板内部引用无效、表45 TextCode 四位十六进制转义。尚未逐条核对整个格式，不据此作完整合规认证。下述合成结果不填补这一规范语义证据缺口。

## 合成与安全回归

维护验证日期：2026-10-26 UTC。使用 Python 3.13.12 / Expat 2.6.3，`-I -S -B`，无需安装第三方包。

从仓库根目录运行（`python` 替换为宿主已确认兼容的解释器）：

```console
python -I -S -B skills/ofd/scripts/read_ofd.py --check
python -I -S -B -m unittest discover -s skills/ofd/scripts -p 'test_ofd.py' -v
python -I -S -B skills/skill-development-standards/scripts/check_skill.py skills/ofd --strict
```

独立分发包的测试命令为 `python -I -S -B -m unittest discover -s "<skill_dir>/scripts" -p 'test_ofd.py' -v`；这是合成维护验证，不必在每次业务读取时执行。结构检查器属于仓库维护资源，不在本独立包中。

27 个合成测试通过，覆盖：字面文字与坐标来源、存储顺序、模板去重与无效嵌套忽略、空白/扫描/未知对象、字体资源与签名元数据、附件/注释分离及不执行、规范点段归一化、越包根穿越及外部引用、重复 ZIP 与符号链接、UTF-8/UTF-16 DTD/实体拒绝、加密标志拒绝、畸形 XML、ZIP CRC、伪造大小与 CRC 的 DEFLATE/STORED 流、非支持压缩、各主要资源限额、CLI complete/partial/unsupported/failed、共享页大属性输出放大、异常 TextCode 父子结构、所有已解析 XML 的外来命名空间诊断与隔离、自检 zlib 可用与不可用。

安装隔离验证将独立读取脚本复制到本次独占临时目录，目录只读、文件只读，在另一个任务目录以空 PATH 调用两次，比较输出和安装前后 SHA-256；通过，未依赖办公软件、网络或第三方包。未在不同操作系统、不同 Python 小版本或操作系统强制只读挂载上验证；chmod 测试不等于所有宿主权限模型认证。

## 独立审查与静态检查

独立审查实际复现了共享页输出放大、异常位置 TextCode 静默遗漏、外来命名空间文字混入三个问题；已修复并新增永久回归。节点预算与字符成本预算分别限制解析缓存复用导致的展开。后续复核还发现并修复 Content 外对象、公共数据/资源命名空间误识别、zlib 自检缺口及 STORED 大小伪造；均有回归，STORED 原反例另经独立复验确认拒绝。最终回归在修复后执行，不以跳过测试掩盖边界。

结构检查使用仓库自带的 Python 标准库检查器，覆盖元信息、文件命名、引用和 Python 语法；不代替安全或格式语义验收。人工核对常量与局部变量命名、外部 XML 标签未被改名，运行模块不跨 Skill 导入。未执行 pylint 命名检查：该开发工具不可用，未安装；不能宣称其诊断已清零。description 人工核对了“读 OFD 文字及元数据”适用与“OCR、转 PDF、验签、生成”不适用请求；没有运行模型触发准确率评测。

## 依赖审计

技能入口仅导入 Python 标准库模块；无第三方 Python 包、外部命令解析器、OCR、Office、PDF 工具或转换器，不安装任何组件。解释器须自带所需 zlib 与安全版本的 Expat；缺失时停止，不要求另装系统软件。测试中的 subprocess 只启动同一 Python 解释器，空 PATH 隔离测试无需外部可执行程序。平台 Library 仅传输交付文件，不在分发包内，也不是运行依赖。未将任何外部软件生成的历史对照材料作为纯标准库数据验收结论。

## 发布验收

版本化分发包位于仓库 `skills/ofd-<version>.zip`，与其他技能的现有位置一致。分发 ZIP 应仅包含 `ofd/` 下实际源码、引用和依赖声明；成员名与源目录一致，不含任务原件、临时产物或缓存。发布时重新读取 ZIP、比较每个成员 SHA-256、从解包副本运行测试，再交付包的实际路径与哈希。源资源不需要特殊文件名映射，也不在执行时改名。ZIP 的 SHA-256 在外部交付记录给出，不写入包内造成自引用。
