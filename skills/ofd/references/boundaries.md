# 能力矩阵与安全边界

路径占位符说明：`<skill-root>` 是 OFD Skill 根目录的文档占位符，不是实际目录或 Shell 变量。取得宿主本次实际读取 OFD 主入口 `SKILL.md` 的真实 `file_path`，若为相对路径，先按该次读取时宿主已确认的基准目录解析为绝对路径，再去掉末尾文件名；所得目录才是 `<skill-root>`，不是当前参考文档所在目录。读取资源或执行命令前，将路径中的 `<skill-root>` 整体替换为该真实目录，保留其后的资源路径；命令中将替换后的完整路径作为一个参数正确引用，嵌入 execute 字符串时按其语法转义。不要将占位符原样交给文件工具或执行器，不按当前工作目录、其他会话路径、环境变量或宿主掩码猜测。无法取得主入口的真实读取路径时，停止依赖操作并报告无法定位。

## 路径与引用策略

主机输入与包内 ST_Loc 是两类边界。CLI 的主机输入以可信任务目录描述符逐级 nofollow 打开，拒绝路径所有层级的符号链接；读取前后核对同一普通文件描述符的大小和修改信息。不具备这些标准库平台能力时明确 unsupported，不安装其他软件或退回不安全路径。默认 API 的路径由调用者授权，可显式传入可信 task_root 获得相同限制；这些检查不等同于防范特权并发写者的操作系统沙箱。

包成员要求大小写敏感、唯一、规范的正斜杠路径。拒绝绝对成员名、反斜杠、空段、点段、父目录段、冒号、百分号、查询/片段、控制字符、符号链接及设备成员。ST_Loc 引用允许 `.` 和 `..`，逐段归一化，但任何尝试越出包根的引用均失败；ZIP 成员名仍必须规范，不接受点段。引用以所在 XML 的目录为基准，前导单斜杠表示包根；它永不映射到主机绝对路径。资源 `BaseLoc` 作为资源目录。仅跟随文档、页、模板、资源、相关索引与签名的显式支持引用；动作和未知扩展不跟随，明确诊断。不存在网络客户端、外部进程或附件执行入口。

安全不依赖文件扩展名。所有读取的 XML 均由 Expat 解析，拒绝 DOCTYPE、实体声明、外部实体和参数实体。UTF-16 同样适用，不用字节关键词过滤代替解析器回调。根必须使用 2016 OFD 命名空间；外国命名空间子节点诊断。XML 未引用成员只列目录，未检查其语义；未解析 XML 成员触发 partial，二进制成员不解码或验证其格式。

## 固定资源上限

| 项目 | 上限 |
|---|---:|
| 输入 | 64 MiB |
| ZIP 成员数 | 4096 |
| 单成员声明解压大小 | 16 MiB |
| 全包声明解压大小 | 128 MiB |
| 单成员压缩比 | 200:1 |
| 单个 XML / 累计唯一 XML | 2 MiB / 32 MiB |
| 累计解析节点 / 展开遍历节点 | 各 100000 |
| XML 深度 / 每元素属性数 | 64 / 128 |
| 累计 XML 字符数据 | 8 Mi 字符 |
| 页面 / 引用解析次数 | 2000 / 10000 |
| 模板嵌套 | 不递归；内部 Template 引用无效并诊断 |
| 成员名长度 | 1024 字符 |
| 展开输出保守成本 | 64 Mi 字符（每节点 8192 + 原始字符数 × 8） |

限额硬失败，不截断交付。XML 缓存只避免重复解析，展开预算另行限制共享页/模板导致的输出放大；每个实际输出记录还在追加前按 JSON ASCII 编码字符长度累计，保留 1 Mi 字符用于封装，覆盖多 TextCode 重复父对象属性的放大。ZIP 读取检查 CRC 和实际解压；二进制元数据只检查声明值，不读取其负载。总量限额不等于操作系统内存/CPU 隔离；高风险批处理仍应由宿主提供独立进程与超时。安装目录可只读，运行时不修改资源、不共享临时路径，重复调用结果确定。

重复的页面或模板 Content、DocBody Signatures 会造成单值结构歧义，读取器明确拒绝，不合并或只取第一项。
