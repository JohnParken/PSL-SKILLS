# 有界会计格式解释

路径占位符说明：`<skill-root>` 是 WPS Skill 根目录的文档占位符，不是实际目录或 Shell 变量。取得宿主本次实际读取 WPS 主入口 `SKILL.md` 的真实 `file_path`，若为相对路径，先按该次读取时宿主已确认的基准目录解析为绝对路径，再去掉末尾文件名；所得目录才是 `<skill-root>`，不是当前参考文档所在目录。读取资源或执行命令前，将路径中的 `<skill-root>` 整体替换为该真实目录，保留其后的资源路径；命令中将替换后的完整路径作为一个参数正确引用，嵌入 execute 字符串时按其语法转义。不要将占位符原样交给文件工具或执行器，不按当前工作目录、其他会话路径、环境变量或宿主掩码猜测。无法取得主入口的真实读取路径时，停止依赖操作并报告无法定位。

解释最多四个位置分段（正数、负数、零、文本），支持常用货币符号、千分位、0–12位小数、负数括号及零破折号。以未舍入的原Decimal选择数字段，负零按零处理；负数字段按绝对值格式化，不自动添加未声明的负号。舍入仅用于解释显示，不修改原数值。

`_`的字符宽度留白与`* `列宽填充明确省略，返回alignment_omitted和display_width_verified=false。display_text只是移除对齐后的符号/数字序列，不是Excel页面渲染，也不推断货币代码。原始格式字符串及selected_section保留，方便对照。

只接受受限数字与货币/括号组合。条件、颜色、区域指令、百分比与缩放混合、任意文字、复杂转义、科学计数、分数等继续unknown，所有位置段先验证，不因当前值没用到错误段就忽略它。文本段仅允许@。长度255及原Decimal精度/指数预算沿用。

公开Microsoft格式说明指出四段次序、两段正零/负数规则、下划线字符宽度与星号填充；原链接记录在依据 (`<skill-root>/references/accounting-format-evidence.json`)，运行时不联网。
