# 有限条件、区域指令与双来源数字格式

路径占位符说明：`<skill-root>` 是 WPS Skill 根目录的文档占位符，不是实际目录或 Shell 变量。取得宿主本次实际读取 WPS 主入口 `SKILL.md` 的真实 `file_path`，若为相对路径，先按该次读取时宿主已确认的基准目录解析为绝对路径，再去掉末尾文件名；所得目录才是 `<skill-root>`，不是当前参考文档所在目录。读取资源或执行命令前，将路径中的 `<skill-root>` 整体替换为该真实目录，保留其后的资源路径；命令中将替换后的完整路径作为一个参数正确引用，嵌入 execute 字符串时按其语法转义。不要将占位符原样交给文件工具或执行器，不按当前工作目录、其他会话路径、环境变量或宿主掩码猜测。无法取得主入口的真实读取路径时，停止依赖操作并报告无法定位。

格式条件只比较已保存的有限 Decimal 与常量，不读取其他单元格、不执行公式，也不实现工作表条件格式规则。接受 `>`、`>=`、`<`、`<=`、`=`、`<>`，每个常量最多64个数字；仅一至两个前置条件与最后一个无条件后备段（共2或3段）。先从左到右匹配；每一段都必须落入现有简单数字/货币/百分比/缩放语法，包括未被选中的段。日期、颜色、表达式、空段、引号文本及无最终后备段继续unknown。格式总长仍限255，不递归解释任意条件。

结果保留原始format_code，另给selected_section、selected_format_code、常量/比较结果和condition_policy。原Decimal不变，显示仍不是Excel完整渲染。

区域前缀仅识别有界 `[$符号-十六进制ID]` 并保留原始符号、ID和未解析标志；不查系统locale、不猜货币代码、分隔符、语言、历法或特殊F800含义。结果保持unknown/locale_display_not_interpreted，无display_text。区域数据解析不是本地化显示支持。

无显式单元格样式时，行、列两个来源只有各自有效启用、能可靠解析且数字格式ID相同时才解释。结果记录两份依据和row_and_column_equivalent；这是数字格式的等价证明，不是推测行列样式优先级，不能推广到字体/边框或条件样式。不同格式、无效索引或未启用来源仍unknown。显式单元格样式处理不变。

依据和原始URL见格式证据 (`<skill-root>/references/conditional-format-evidence.json`)。Microsoft官方说明给出了比较操作/常量、分段、倍率与语言区域依赖；本实现主动限定为确定的纯数值比较子集。区域前缀依据官方NumberingFormat里的内建示例，只保存语法，不保证ID语义。

新增test_wps_format_rules.py为标准库合成独立预期，包含Decimal精度、各运算符、首匹配/后备、完整格式保留、非法/预算/公式拒绝、区域元数据和双来源相同/冲突。没有真实含条件格式及行列双来源文件的独立显示对照，不能据测试通过称真实验收。
