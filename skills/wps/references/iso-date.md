# OOXML 保存的 ISO 日期子集

路径占位符说明：`<skill-root>` 是 WPS Skill 根目录的文档占位符，不是实际目录或 Shell 变量。取得宿主本次实际读取 WPS 主入口 `SKILL.md` 的真实 `file_path`，若为相对路径，先按该次读取时宿主已确认的基准目录解析为绝对路径，再去掉末尾文件名；所得目录才是 `<skill-root>`，不是当前参考文档所在目录。读取资源或执行命令前，将路径中的 `<skill-root>` 整体替换为该真实目录，保留其后的资源路径；命令中将替换后的完整路径作为一个参数正确引用，嵌入 execute 字符串时按其语法转义。不要将占位符原样交给文件工具或执行器，不按当前工作目录、其他会话路径、环境变量或宿主掩码猜测。无法取得主入口的真实读取路径时，停止依赖操作并报告无法定位。

单元格 t=d 是显式日期类型。本实现保留原字符串为 type=text/value，同时附加 source_cell_type=d 与 iso_date；下游不会自动把它计入数值合计。它与数值日期序列不同，不应用1900/1904偏移，不作UTC或时区转换，不重算公式。

限定公历0001–9999、YYYY-MM-DD、可选T小时:分钟和可选秒/1–9位小数秒；可选Z或±HH:MM时区（最多14:00）。无时区表示unspecified，不猜本地时区。原小数精度完整保存，不通过datetime微秒截断。负年份、扩展年份、周/序数日期、基本格式、24:00、闰秒等不在本子集；合法性无法保证的词法返回unsupported，范围内非法日期/时间返回corrupt。

公式缓存仅原样读取并标未验证；缺v仍为missing，空v不是空成功。日期显示样式、有效样式继承、语言环境与完整ISO8601渲染不在范围。测试均为合成规范样例，尚无真实WPS内部ISO日期的独立内容对照。

官方开发依据见来源记录 (`<skill-root>/references/iso-date-evidence.json`)，运行时不访问网络。
