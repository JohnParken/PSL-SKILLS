路径占位符说明：`<skill-root>` 是 WPS Skill 根目录的文档占位符，不是实际目录或 Shell 变量。取得宿主本次实际读取 WPS 主入口 `SKILL.md` 的真实 `file_path`，若为相对路径，先按该次读取时宿主已确认的基准目录解析为绝对路径，再去掉末尾文件名；所得目录才是 `<skill-root>`，不是当前参考文档所在目录。读取资源或执行命令前，将路径中的 `<skill-root>` 整体替换为该真实目录，保留其后的资源路径；命令中将替换后的完整路径作为一个参数正确引用，嵌入 execute 字符串时按其语法转义。不要将占位符原样交给文件工具或执行器，不按当前工作目录、其他会话路径、环境变量或宿主掩码猜测。无法取得主入口的真实读取路径时，停止依赖操作并报告无法定位。

只接受 Transitional 工作表的 comments 与 vmlDrawing 内部关系，验证 legacyDrawing 的唯一关系 ID、内容类型、无后续关系和跨工作表部件归属。Strict VML、外部链接、脚本、图片、控件、公式和未知元素/属性继续拒绝。

VML 根必须是无命名空间 xml。只接受传统 Note 形状、已知装饰元素和空 textbox；装饰不渲染，不把 VML 文字当批注。每个 ClientData 的 Row/Column 为零基单元格位置，必须与唯一 comments.ref 对应；必须一对一，缺失、重复、越界或无归属均拒绝。

Anchor 的八个原整数依次为左列、左偏移、上行、上偏移、右列、右偏移、下行、下偏移。列与行按 OOXML 上限检查；偏移限定非负且最多1000000，不解释像素或列宽。仅保留矩形数据与源路径，不计算页面位置、可见性或视觉重排。本地 shape type 片段引用只保留，明确未解析，不加载任何资源。结果仍 partial，layout_decoded=false。

既有 XML 全局节点预算先于本模块分配；另限制 VML 节点50000、Note形状4096。每部件字节限制、深度和原包 CRC、关系目标校验保持。模板参数与装饰仅允许逐元素明确属性，未知形状不能靠宽泛 opaque 接受。

验证是标准库合成包：一对一锚点、矩形、关系ID/类型、缺失重复越界、逆向矩形、未知/活动属性、非空textbox、外部关系及预算。无真实 WPS 批注锚点显示对照。
