# MS-DOC 主正文版本边界

公开依据记录在 [格式依据](format-evidence.json)，对应 MS-DOC 2.5.1、2.5.7、2.5.10–14。这里的版本表示正文存储结构，不证明生成软件或所有版本功能都已支持。

| 有效 nFib | fc/lcb 对数 | cswNew | FIB 排他结束偏移 |
|---|---:|---:|---:|
| 0x00C1 | 93 | 0 | 900 |
| 0x00D9 | 108 | 2 | 1024 |
| 0x0101 | 136 | 2 | 1248 |
| 0x010C | 164 | 2 | 1472 |
| 0x0112 | 183 | 5 | 1630 |

固定 csw=14、cslw=22；fc/lcb 从偏移 154 开始。先按对数定位扩展，再按 cswNew 是否为零选择 base nFib 或 nFibNew，最后校验上表完整组合。不能仅改 nFib 或对数来宣称对应版本有效。每个版本的全文头长度先检查，片段不能与它重叠；cbMac、字符/片段预算、CLX 长度和正文 CP 范围仍受原有校验。

D9 使用 FibRgFcLcb2000，继承 97 前缀；112 使用 FibRgFcLcb2007，继承 2003 前缀。正文仍使用 97 前缀中的 CLX 第 33 对和同一片段表语义，不从扩展字段推测新正文位置。非正文扩展结构、格式、修订与布局不在恢复范围，不因字段长度存在而声称它们经过语义验证。

D9/101/10C 的扩展含 nFibNew 与 cQuickSavesNew（0–15）。112 另有三个主题语言 16 位字段，公开规范要求忽略其值；读取其完整六字节只用于确认未截断，不把其值当语言或编码选择。nFibBack 仍仅 BF/C1；加密和对象/字段策略不变。

D9/112 仅有明确标注的标准库合成验证：中文与压缩片段、物理逆序、跨片段代理对、两种 Table 选择、主正文排除页眉、空正文、实际 CFB 入口、完整扩展逐字节截断、版本/长度组合、主题字段、FIB 交叠、CLX 指针/长度、加密和资源限额。没有这两个有效版本的真实 WPS 样本或独立内容对照；不能将合成通过称为完整版本或真实软件兼容认证。
