# ET/ETT 读取容量与稳定性

先完成 [执行环境自检](../SKILL.md#执行环境约束与首步自检)。本轮增强针对内容被识别为 CFB/BIFF8 的 ET/ETT；OOXML 仍走自身读取分支。未知私有结构不猜测，不执行公式、宏或外链，不应用注音显示，不写回输入文件。

## 新增可读范围

- SST 共享字符串可以附带注音扩展。单元格仍只返回原来的主文字，附加 `shared_string_phonetics` 按 SST 索引保留原始 ExtRst 字节与来源；注音结构、读音及显示未解释，结果为 partial。
- 文字、FormatRun 与注音原始字节分别处理跨 Continue 记录的边界；字符续段消费编码字节，原始元数据续段不消费编码字节。固定头不得跨记录，负长度、截断及超预算明确拒绝。公式 String 缓存仍只支持原有纯文字子集。
- 共享字符串独立数量上限从 10000 提高至 200000；仍受 8 MiB 流、100000 条记录、32767 码元单字符串、8 Mi UTF-16 单元格输出文字及 16 MiB JSON 等预算限制。达到数量上限不代表任意长度组合都可接受。
- 合并范围总量从 256 提高至每工作簿 65536，保留范围与非锚点数据，不展开单元格。重叠检测使用行边界扫描及 256 位列占用掩码，避免逐对比较；边界相邻允许，共享一个单元格也拒绝。
- 小范围表头读取不会仅因其他行存在超过 10000 个合并范围而失败；实际表头仍受区域、完整合并边界、非锚点内容和单元格预算检查。

相邻 xlsx 技能的 WPS JSON 分析适配器仍限定每表 256 个合并范围；本批未修改该技能。超过该范围的读取结果可使用本包的显式表头入口，但不能假定所有下游分析工具同步支持新容量。

## 失败结果

BIFF 解析异常可附带已记录的工作表、记录 ID 和 Workbook 流偏移；字符串失败还可包含 payload 偏移。统一入口将这些位置保留在 `location`，不复制失败记录中的正文。无可确认的位置时不推测。

资源耗尽（包括合并数量、共享字符串数量、元数据及诊断条目）明确为 `resource_limit`；未知特性仍为 unsupported，其他结构不满足条件仍按原契约报告 invalid_or_unsupported。增强定位不把所有拒绝都归类为文件损坏，也不在失败后交付未经完整检查的部分工作表。

文件入口默认 data，预先选择已有元数据白名单及有界 opaque 图表策略；显式 strict/legacy 和 chart-policy reject 保留。选择发生在一次解析前，不会在拒绝后重试或重同步；详见 [当前数据读取策略](biff8-readonly.md#default-data-policy)。

## 验收边界

新增注音、容量和位置行为以标准库合成样例验证；合并检测另与小范围独立单元格枚举结果比较。四份已有真实 ET/ETT 用于回归及保存值核对，不包含新增注音或极大容量特性的生产证据。不能把容量提高或合成通过写成完整原生 ET 兼容。

规范定位见 [ET 格式依据](et-format-evidence.json)。现有来源不保证覆盖用户的每一种 WPS 版本；具体失败文件仍须核对实际容器、拒绝记录及独立内容预期。

实际运行结果见[验证记录](validation.md#历史证据)及[本批证据摘要](reading-enhancement-evidence.json)。

## 默认数据读取与失败分类

data 只扩大已知非值语义的可读范围，不跳过单元格或工作表。样式、打印、窗格、分页及支持的图表保持原始字节与诊断，不能解释为完整显示或私有 ET 支持。容器偏差及其他未解释流也导致 partial，不再藏在来源字段里而显示 ok。

未知记录、外部链接结构、宏、加密、结构/边界错误、重复坐标、损坏 SST/Continue、非有限数和资源上限继续拒绝；不会返回半解析工作簿。缺失的公式 String 缓存仍明确 missing，并将 cell_value_coverage 降为 missing_formula_caches，不作空白或缓存正确性推断。分析端的公式默认拒绝和 missing 缓存拒绝不变。

这是默认策略改进，未新增 Note/HLink/条件格式等记录解码，也未扩展私有格式、安全限额或图表类型。新增默认行为与严格行为成对验证；真实四份 ET/ETT 从默认失败变为 partial，独立冻结的 198 个保存值（含 33 个未重算缓存）保持一致。空 ET 不证明有内容 ET 的兼容性。

## 纯表格 Unicode 声明与保留位

data 在原有 BIFF8 范围内新增 CodePage 932/936/1252 声明接受，普通 Label、String 缓存与 Format 的 Unicode 头保留位按规范忽略，保留原始标志及位置并报告 partial。不是按代码页猜解码，不扩展 BIFF 版本、SST/Continue 标志或未知记录。完整范围与证据限制见 [纯表格兼容](biff8-readonly.md#pure-table-unicode-compatibility)。
