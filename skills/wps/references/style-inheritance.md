# 有界数字格式样式来源

仅解释数字格式，不声称字体、主题、条件格式或完整显示恢复。原数值、单元格 XF 索引及格式记录保持；`numeric_interpretation.number_format_source` 记录直接 XF、父样式索引、保存格式与 apply 标志。

公开结构的继承是两层：cellXfs 的 xfId 引用 cellStyleXfs，后者不允许 xfId。因此不存在需要正常递归求值的合法样式链。本实现每集合最多4096项；对非法父链只作最多32步诊断，发现循环、越界或过深即 unknown，不沿非法链取得格式。声明 count 与实际数量不一致拒绝。

- 明确 applyNumberFormat=true：使用 cellXF 保存的数字格式，若提供父索引则先校验引用。
- applyNumberFormat=false 或省略：只有有效且启用数字格式的 parentXF 与 cellXF 的保存 numFmtId 一致才确定该数字格式。Office 对此标志的实现是允许父格式的后续变化覆写保存副本；不是无条件把不同父格式套到单元格。
- 父格式不同、缺父、父数字格式关闭、非法链：unknown，保留冲突依据，结果 partial；不猜哪个软件的显示行为。
- 无单元格显式样式时，沿用现有单一明确行/列来源策略，但该来源也可通过上述有效两层一致检查。双来源不猜优先级。

现有格式白名单仍决定是否能解释显示；即使来源确定，复杂格式仍 unknown。新增行为仅标准库合成测试，包含确定来源、直接覆盖、关闭、冲突、非法循环/深度/越界、count/配额及真实解析入口；未取得真实 WPS 独立显示对照。
