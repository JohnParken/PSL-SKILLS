# 有界会计格式解释

维护资源说明：文中 `docs/maintenance/et/` 与 `skills/et/scripts/test/` 均以宿主确认的仓库根目录为基准，仅供源码维护，不随运行包分发；运行任务不读取或执行。没有仓库时跳过维护资料，不按 Skill 安装目录拼接。

路径占位符说明：`<skill-root>` 是 ET Skill 根目录的文档占位符，不是实际目录或 Shell 变量。取得宿主本次实际读取 ET 主入口 `SKILL.md` 的真实 `file_path`，若为相对路径，先按该次读取时宿主已确认的基准目录解析为绝对路径，再去掉末尾文件名；所得目录才是 `<skill-root>`，不是当前参考文档所在目录。读取资源或执行命令前，将路径中的 `<skill-root>` 整体替换为该真实目录，保留其后的资源路径；命令中将替换后的完整路径作为一个参数正确引用，嵌入 execute 字符串时按其语法转义。不要将占位符原样交给文件工具或执行器，不按当前工作目录、其他会话路径、环境变量或宿主掩码猜测。无法取得主入口的真实读取路径时，停止依赖操作并报告无法定位。

解释最多四个位置分段（正数、负数、零、文本），支持常用货币符号、千分位、0–12位小数、负数括号及零破折号。以未舍入的原Decimal选择数字段，负零按零处理；负数字段按绝对值格式化，不自动添加未声明的负号。舍入仅用于解释显示，不修改原数值。

`_`的字符宽度留白与`* `列宽填充明确省略，返回alignment_omitted和display_width_verified=false。display_text只是移除对齐后的符号/数字序列，不是Excel页面渲染，也不推断货币代码。原始格式字符串及selected_section保留，方便对照。

接受受限数字、货币与括号组合。负数段支持显式前导负号或括号，括号内外均可保存货币符号。数字段可用 `0.##` 或 `0.0##` 表示可选小数，并可用命名颜色或 `Color1` 至 `Color56` 开头。结果附所选段的 `format_color_raw`。条件、区域指令、百分比与缩放混合、任意文字、复杂转义、科学计数和分数超出位置多段子集。先验证全部位置段，文本段仅允许 `@`。格式长度及 Decimal 精度和指数沿用现有预算。

公开Microsoft格式说明指出四段次序、两段正零/负数规则、下划线字符宽度与星号填充；原链接记录在依据 (`docs/maintenance/et/accounting-format-evidence.json`)，运行时不联网。

测试是标准库合成样例，不是WPS显示验收。既有Balance_Sheet.ett的181格式原始字符串落入本子集，可只读检查解释结果，但没有Office或同源独立显示对照；不据此声称真实显示等价。

独立的简单数字条件子集见条件与区域指令 (`<skill-root>/references/conditional-number-formats.md`)，不将本会计语法任意嵌入条件公式；区域前缀仅保存元数据。
