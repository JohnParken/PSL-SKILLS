## 独立审查

- DOCX 主 story 编号按正文、表格、嵌套表格顺序预遍历一次，标签即时计入文本预算；文本框不偷用主 story 计数。单元格编号与原文字分列。OMML 保留有序存储文本，不以拼接文本冒充数学语义，明确 partial；未知块、altChunk 和单元格结构修订保留缺口诊断。
- WPS 的 MC Requires 在实际命名空间作用域解析，选首个受支持 Choice，否则 Fallback；排除修订不触发无关分支诊断，无可选分支仍保留不确定性，不按文字内容删除独立对象。
- WPS 图表仅沿当前源部件内部关系读取，共享 XML 预算，不访问外链/嵌入工作簿。原始数值字符串、类别与缺值范围保留；128 引用、50000 点、10000 series/cache 记录及 2 Mi 字符预算，安全和资源失败不吞。重复语义字段明确诊断，不声称完整还原。
- 新模块只依赖本技能模块和标准库，没有跨技能运行时耦合。源码夹具仅负责在隔离运行前生成合成输入；被验收的只读包禁止读取仓库与相邻技能。

- ET 默认保留已读类型化单元格、图表保存点、缓存与缺项；明确 blank 以精确区间表示，空文本、公式缺缓存、坐标不确定和错误格不混同。`--profile full`、原 Python/API 和 XLSX 消费协议维持原结构。公开原件和安全预算证据见 [ET记录](../maintenance/et/visible-content-20261116.md)。
- TL-DOCX 默认去内部部件/路径/指纹/默认选项回显；保留内容、图表、覆盖和必要续读令牌。`--full`、`--content --details` 保留高级读取；新投影和解析器版本参与游标绑定。证据见 [TL-DOCX记录](../maintenance/tl-docx/visible-content-20261116.md)。
- WPS 默认 CLI 精简内容包括支持的 OOXML/二进制图表保存值；`--profile full` 与显式 standard/maximum 兼容原结构，Python read/read_bytes 不被投影替换。OOXML 主文、相关区域、嵌套单元格按实际节点身份输出顺序，不按文字全局去重；RTF 也保留块顺序。二进制 text 与表格仍可能重复，不宣称全格式消重；嵌套证据明确只是已确认行片段，不补造完整父表。
