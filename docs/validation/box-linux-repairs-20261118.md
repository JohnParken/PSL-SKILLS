# Box Linux 修复复验

2026-11-18 在 Box `main` 的 Ubuntu 24.04.5 LTS x86_64 上，以 UID 1000 和独立预置的 Python 3.12.16、Expat 2.10.0 测试。基线为 `7b505998d2be1db7a91ecb43813c9ad3926e858c` 加工作区补丁。五个受影响 Skill 的版本为 `20261118.1520.5095`，人工复核 description 的适用范围后保留原描述。

## 修复

- TL-PPTX 同步审阅后的运行文件哈希、来源记录及清单固定摘要。原包通过门禁，加入未知脚本、改动或移除许可、清单及运行文件仍被拒绝。使用已装的 Liberation Sans 测试字体，按字体实际族名验证字形轮廓。
- DOCX 入口从 8,696 字节降至 7,988 字节，保留简单创建、自然分页、字体编辑和归档状态的必要指令。同步更新规划式加载快照。该快照记录文件字符和字节，未测量宿主读取或 token。
- WPS 持有候选创建描述符直到清理完成，防止原候选被替换后 inode 被立即复用。公开回执继续报告被替换文件保留及清理未完成。
- PPTX 与 TL-PPTX 对齐宿主结果引用指引，PPTX 明确顶层附件定位。仓库契约测试以显式发布清单核对 Skill 集合。TL-PPTX 用 `sys.platform` 和标准库随机数生成替代系统探测，TL-DOCX 三个维护基准以 `sys.platform` 记录运行平台。
