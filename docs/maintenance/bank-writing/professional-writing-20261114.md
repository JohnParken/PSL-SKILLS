# 专业写作规则增强与验收

本轮只修改 bank-writing 文本规则及仓库说明，不新增生产脚本，不提交/推送，不保存私人材料。

## 改动

- 审校的风险词替换表改为事实核查和最小修复；删除公文范例无依据补写的经营贡献、担保情况和违规原因。
- 贷款比例、预警阈值、检查周期、客户准入、担保义务与处罚条件改为依据已核实适用规则；不以模板授权授信、处分或限制服务。
- 法规引用需来源、版本、范围和条款；去掉不可靠法规名及示例条款的直接套用。不宣称本次进行了现行法律全面审查。
- 入口新增轻量任务卡与证据边界；无脚本任务不再要求执行器路径映射。月报路由同步至综合写作，准确性优先于对仗。
- 新增年度规划/经验材料证据要求、文种最小要素及三级审校。普通文本只按需加载对应参考，没有新增宿主调度、自动缓存或全量预读。

## 合成审查

| 输入/情境 | 预期行为 |
|---|---|
| 已确认掩盖不良，要求“写得合规” | 保留事实和影响，不替换成正常重组 |
| 只给投诉8件增至15件 | 只算增加7件；比较期不明不自动写环比，不补原因，不据件数判断服务好坏 |
| 缺制度，起草授信/客户准入 | 条件、比例、周期和担保待核，不用模板决定资格 |
| 会议仅有人提出建议 | 不写已形成会议决定 |
| 年终材料含下年计划 | 与成果、已批目标和预测分开 |
| 局部修改数字并要求保留段落 | 保留锁定与删除记录，必然相关计算最小联动 |

独立审查代理按上述情境检查文本，发现旧公文表、预警阈值、披露措辞与处置要求残余；已逐项修正。此为人工规则审查与合成演练，不是生产 DeepAgents 模型执行结果。
