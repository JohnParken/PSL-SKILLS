## 规范与实施范围

- [Microsoft Excel 97–2007 Binary Specification](https://download.microsoft.com/download/5/0/1/501ED102-E53F-4CE0-AA6B-B0F93629DDC6/Office/Excel97-2007BinaryFileFormat%28xls%29Specification.pdf)：BOF 页 43–44。BIFF5 和 BIFF7 同用 0x0500、8 字节载荷，不能单凭 BOF 区分产品。
- [OpenOffice Excel File Format](https://www.openoffice.org/sc/excelfileformat.pdf)：2.5.2 字节字符串、5.17 CodePage、5.50 Formula、5.63 Label、5.95 Sheet、5.102 String、5.115 XF。与 BIFF8 的 Unicode、16 字节 BOF、20 字节 XF 等分开处理。
- [MS-XLS XLUnicodeRichExtendedString](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-xls/173d9f51-e5d3-43da-8de2-be7f22e119b9)：SST 保留位忽略，但 fRichSt/fExtSt 和所有长度必须保留；Continue 字符编码及固定头分界不放宽。

新增独立 `skills/et/scripts/wps_biff5.py`，复用同技能的安全分帧、预算/原始证据保留与结构化结果组装，不复用 BIFF8 的字符串、样式或公式语义。输出 `biff5_readonly_v1` 和 `biff5_subset`。核心记录为 Number/RK/MulRK/Blank/MulBlank/BoolErr/Label/Formula 保存缓存；只按明确且一致的受支持 CodePage 严格解码。不确定文字、缓存及表归属省略并保留 partial/覆盖风险，不生成猜测值。

SST 另覆盖保留位、零个 rich run、错误 total 不钳制非负 unique；保留索引、位置、原 flags。负 unique 不扫描猜测；超预算仍硬拒绝；损坏后不重新同步猜索引。
