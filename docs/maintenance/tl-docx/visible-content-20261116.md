## 改动与契约

- 默认读取升级为 `content-v2`，普通正文、表格所有行、文本框、保存的图表系列/点仍直接输出。纯结构、文档属性、字段指令、内部部件/工作簿坐标不再占据默认内容；`--details` 保留定位，`--full` 保持原完整记录。
- 表头保留候选/确认状态、行范围与诊断；实际文字只在原行。合并关系保留单元格 origin、row_span、非默认 colspan，去除重复表/行分组标签。普通值 colspan=1、vmerge=null、零网格偏移等按读取参考的默认规则省略，不能解释为丢失合并。
- 编号标签与实际字段结果保留；已有段落中的字段结果不再重复。图片未 OCR/图形未渲染在 coverage 统一说明，不逐图片重复长提示。图表原值相同的 raw/missing display 副本省略，不支持格式与近似百分比状态仍保留。
- 新增显式保存的轴标题、自定义数据标签，保留系列/点关联和文字段落分隔，明确删除的数据标签不显示。缺缓存不计算、不取外链；不声称还原所有渲染标签、隐藏值可见性或视觉页序。
- 公开 API 仍为 1，新能力 `visible-content-v2`、`stored-chart-annotations`；投影/解析变化已更新游标 `read-view-v6` 与缓存 `tl-report-6`，旧 token 不混用。跨技能未改其他提供方或守卫。
