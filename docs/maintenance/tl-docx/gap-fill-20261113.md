# TL-DOCX 与 DOCX 差距补齐验收

基线：主干 `a880946419e2348aafb50949071496b7558a174e`；对照 `docx` 版本 `20261113.2302.5108`。本轮只维护 TL-DOCX、相关项目说明、分发清单与集成测试，没有修改 DOCX 代码或公共归档副本。TL-DOCX 当前版本 `20261114.0637.2065`。

## 实际补齐

- 四种固定 Profile；正文、标题、副标题、四级标题、表格正文/表头角色样式；块级 format/align 和中西文字体独立覆盖。明确优先级、非法值和互斥模式，保留无新参数时的原有默认行为。
- 首节和分节毫米宽高、统一/单边边距，与原厘米边距接口兼容；校验正可用尺寸。
- 表级 body_format/header_format 覆盖全局表格文字格式，多行及合并表头不重复处理。
- 独立 reference 块生成 REF/PAGEREF，未知书签拒绝；字段值不由脚本重算。
- 副标题段后恢复为 8 pt，不再错误使用标题 12 pt。
- 有界 basedOn 标题继承、正文脚注/尾注/批注引用记录、概要标题、章节空白规范化。章节统计与全篇覆盖/诊断分别返回，修复末节混入附加文字图表和章节表格省略计数。
- 显式范围的同属性/同格式纯文本 run 合并，保留文字节点和 xml:space；拒绝范围锚点、字段、图像、修订和重复 rPr，非目标包成员保持原解压字节。
- 执行指导明确 execute、禁止 cd、用户文件仅在任务 ./ 顶层查找。保持只读/编辑/归档各自状态，原件不覆盖。

新增 31 个回归；新增运行模块只在 TL 包内，不导入相邻 DOCX，不增加依赖。声明仍为 python-docx 1.2.0，使用 -I -B。

## 剩余差异和迁移边界

- 角色样式当前落实为段落/run 直接格式，尚非 DOCX 的完整原生继承样式；后续在 Word 中修改样式的传播行为不同。
- 未实现 DOCX 的跨次解析缓存和释放、全部历史 CLI/回执/worker 清单兼容、独立字体候选差异工具、受控修订标记写入、解包重包和完整排版检查器。format.tab_stops 未新增，块级 tab_stops 保留。
- TL 结构 schema 与 DOCX 不同；单条大 XML 树不会拆分。此次游标绑定为 read-view-v2，旧游标须从首批重新开始。不能把计数与选节诊断改变伪装成无语义差异。
- DOTX 通用编辑仍窄于 DOCX；批注和模板替换按原契约支持 DOTX。图表工作簿实时值、OCR、完整复杂修订语义和任意无损编辑均不承诺。
