# tl-docx 读写对标验收

本轮发布版本 `20261113.1908.1877`，对照工作树中的 `docx` `20261113.1916.2318`。验证环境为 macOS 27.2.1 arm64、Python 3.14.10、Expat 2.7.4、python-docx 1.2.0。lxml 6.1.3 和 typing_extensions 4.16.0 随 python-docx 安装，运行清单只声明 python-docx。

## 真实月报回归

使用用户本轮指定的同一份 2026 年 10 月“一明”运营分析月报 V3.2。附件只读，测试使用任务副本，测试后复核原件 SHA-256。运行包按 29 项白名单构建，单独解包为只读，空 PATH 下从任务目录运行，拒绝回读仓库源码。测试前后安装和 ZIP 内容一致。

| 核对 | 实际结果 |
| --- | --- |
| 默认完整读取 | 源码与新版只读安装各自回归。相对前版安装包，默认报告 1,224 条、405,580 字节，逐字节一致。覆盖 14 张表、197 行、855 个物理单元格、27 个文本框、11 次图片引用及 2 张图表。 |
| 原始 XML 和结构 | `word/document.xml` 的 2,128,089 字节与直接读取 ZIP 成员一致。正文、样式、编号定义的结构导出共 54,969 个节点，27,389,007 字节，源码与只读安装结果一致。 |
| 修订视图 | 直接在原始 XML 中核查插入、删除、移入、移出标记，月报正文未出现这些标记。三个显式视图的记录和诊断一致；有修订时的差异由合成夹具核验。 |
| 表头和导出 | 按原表格结构核对物理行列。14 张表均可映射逻辑列。第 1 张表全行标为重复表头，回归显式选择首行为表头，报告保留原标记诊断。增强报告 1,254 条、439,417 字节，47 批记录与一次完整导出一致。 |
| 图表和图形 | 40 项图形带定位记录。独立核对原图表 XML，30 个图表点含 12 个缓存值及 18 个空值；18 个空值保留可核对的 A1 来源坐标。因数值缓存缺失和外部工作簿未读取，结果保留 `partial`。 |
| 定点替换副本 | 用只读安装包执行一次精确替换。回执确认 1 次，副本只改变 `word/document.xml` 成员，其他 ZIP 成员解压内容逐字节一致，原件摘要一致。 |
