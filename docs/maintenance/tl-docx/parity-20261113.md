# tl-docx 对标增量验收

Skill 版本 `20261113.1816.0659`，对标当前 `docx` 源码版本 `20261113.1526.2905`。运行时唯一直接依赖 `python-docx==1.2.0`。本轮验收使用 macOS 27.2.1 arm64、Python 3.14.10、python-docx 1.2.0、lxml 6.1.3 和 typing_extensions 4.16.0。

## 结果

| 功能 | 验收证据 |
| --- | --- |
| 线程批注 | 测试新建现代四部件、继续加根批注、同级回复、改删、拒绝级联删除、经典批注、DOTX 和异常元数据。使用当前 `docx` 创建批注、`tl-docx` 回复、再用 `docx` 读回，父子 ID、作者、正文定位均匹配，原文件保留。两端使用合成文档。 |
| 命名 | 用主题自动命名，跳过已占用的主路径及归档路径，按已有版本继续递增。固定名称冲突和输入别名均拒绝覆盖。 |
| 恢复 | 终止子进程模拟已核验但尚未发布、已发布未归档及归档已记录等阶段。原清单恢复保留主文件 inode 和字节，不触发重新生成或归档。替换暂存、修改或移走主文件、复制清单均保留证据并拒绝误清理。 |
| 分页治理 | 12 类风险均有合成用例，覆盖样式继承、段落显式覆盖、缓存分页和分节规则。生成保留合法显式分页、回传建议，`validate --strict-pagination` 有风险时退出 2，结构仍可通过。 |
| 原月报回归 | 新版源码和只读解包后的发布 ZIP 均与首版安装包比对，1,224 条、405,580 字节的读取 stdout 完全一致，源文件 SHA-256 未变化。结果仍因缺少缓存和外部工作簿而为 `partial`。新版静态审计另返回段内分页和标题同页配置提示。 |
