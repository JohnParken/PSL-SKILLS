# TL-DOCX 读取完整性增强验收

版本 20261114.1228.4475，基于本仓库上一轮未提交工作树维护。原 DOCX 未修改，不提交、不推送、不改历史 ZIP。

## 已修复的确定问题

- 合法自定义路径页眉/页脚/样式/编号/核心属性不再因固定文件名而漏读。按关系与 Content Type 定位；孤立声明可读部件标记 orphan_part 和未确认显示关联。
- 非关键附属 XML 普通损坏保留正文及其他部件，明确 partial/unreadable；DTD、危险关系和包级安全限制仍拒绝。图表解析不再把 DTD 拒绝吞成普通图表错误。
- 常见 OMML 公式保留分数、上下标、根式等关系，嵌入段落正确位置，纯文本不再丢失公式。未知结构或近似表达保留诊断，不称完整数学语义转换。
- SmartArt、未知绘图内容、默认视图中的复杂修订不再静默不报。

## 高价值增强

- 散点 x/y、气泡大小及多层类别缓存；原字符串、空值、稀疏点与异常索引保留。未读取嵌入工作簿或访问外链。
- 继承 numPr、多级编号、常见 decimal/letter/Roman/bullet、起始覆盖及重启；不支持中文复杂格式、图片项目符号、复杂链接等显式诊断，不造标签。标签在 JSON，纯文本不模拟完整列表显示。
- 分节记录显式页眉页脚关联，不模拟 Word 的继承或实际每页显示。
- --fragment-records 配合固定字节预算提供无损 JSON 记录分片；字符偏移/完整源摘要/末片信息用于重组。默认输出不变、游标绑定分片选项与预算，缓存状态不改变分片边界。不是输入流式解析，覆盖元信息本身超预算仍需调整。
- 缓存解析版本及读取游标版本升级，旧 token/游标不可混用。
