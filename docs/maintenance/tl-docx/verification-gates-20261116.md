## 变更及独立审查

- `format_run` 新增独立属性白名单差异守卫，不调用编辑 setter 计算预期。覆盖原包解析树到组件加载、每次请求前后，以及已验收快照到最终候选；正文全部非目标节点保留，其他成员仍逐字节核对解压内容。主题字体只清除请求通道的主题引用；显式 RGB 清除颜色主题三属性，下划线保留颜色等未请求属性。字号沿用既有半磅截取及已存复杂脚本字号 round 契约，未借本轮改变精度。
- 重复操作按原有顺序执行并逐步验收，重复的源目标属性拒绝。混合批次的其他编辑仍走原边界，不宣称任意无损编辑；词法 XML 缩进、声明与属性排列不在解析树保护承诺内。签名包保持拒绝。
- 创建入口先规范化并验证输入，独立保存预期副本，枚举全部正文/表格图片并安全读取一次；生成器只拿另一份副本及只读图片取值回调。候选核对正文顺序、列表项文字、逻辑表格/合并、图片字节与替代文字、字段/书签、分节页眉页脚开关及请求元数据。生成器遗漏图片或篡改收到的规格不能同步污染预期。结果放 `result.content_verification`，保留原结构和静态布局检查。
- 门禁不验证字体/全部格式保真、编号显示标签、字段重算或客户端视觉排版，不能把 `verified` 当作视觉验收。
- 缓存 stdout 交接以完整 write 和 flush 成功为边界。固定任务目录描述符，只认领本轮新建/重建 token；失败按既有身份和内容验证清理，复用缓存不认领，其他缓存/未知/变化文件不删除。末页仍输出前释放；部分 stdout 不再追加错误 JSON，清理失败单独 stderr 且非零。真实 broken pipe 进程非零不保证恰好为1（解释器可能再次flush）。强杀和输出成功后宿主丢弃结果不在同步清理保证内。
- 对外 API 仍为1，增加 `creation-content-verification`、`format-run-preservation-guard`、`cache-output-handoff`。解析内容/游标协议未因这些门禁改变。显式运行白名单增加两份核验模块，不导入测试、不跨 Skill 复制业务实现。
