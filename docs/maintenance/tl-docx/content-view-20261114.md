# TL-DOCX 内容优先读取验收（2026-11-14）

基线版本：20261114.1935.3715。仅维护 TL-DOCX；DOCX 运行源码未修改。本报告不保存真实用户文件、文件名、原文或业务数值。

## 已实现

- 单元格按可见段落保留换行、空段和行内分隔；删除内容不因按段遍历重新显示。
- 显式 `--content` 提供内容优先 JSON，旧默认读取 API 保持。只删除已证实的重复表示，未知类型、附加 story 和带语义信息的记录保留；嵌套单元格以有序后续记录避免改变内外文本顺序。
- `--content --details` 保留来源定位与完整诊断；普通内容视图按诊断代码计数并明确详细信息入口，不将省略定位伪装为无诊断。
- 表头区分 confirmed/candidate/none 及依据，首行推断不冒充确认。
- 图表系列说明现存缓存 available/partial/unavailable；有限百分比展示与原值分开，复杂格式保持原值并标记，不联网、不补算缺失数据。
- 图形几何和未知绘图显式 partial，保留可读文字；不执行 OCR 或视觉渲染。
- 游标与缓存读取版本升级，旧 token 不跨版本复用；内容投影在分页前执行。
