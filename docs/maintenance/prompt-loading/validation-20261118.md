基线为 ET 回写集成验证工作树快照，不是重新获取的远端 main，也不是干净 HEAD。保留既有 ET、DOCX、PPTX 等修改；仅整合三技能提示、引用、相关测试和分发清单。未修改业务运行逻辑，未提交、推送或写回 Mac。Mac 的 WPS task_paths 并行修复不在本补丁内。

入口 Unicode 字符数：WPS 11,754 → 7,228（-38.5%）；XLSX 10,809 → 7,606（-29.6%）；OFD 9,295 → 4,955（-46.7%）。普通 XLSX 完整读取由入口加 read-analyze 共 13,988 → 7,606（-45.6%，两次读取变一次）；基础区域统计保持直达，20,643 → 17,440（-15.5%，仍两次读取）。WPS 复杂内容解释需追加 content-reading，11,754 → 10,091（-14.1%，一次变两次）。高级 XLSX 专项新增 task-routes 一次读取，如实计入，不能将入口降幅当所有任务收益。

文件集合、字节、字符及 SHA256 见 [同能力计划比较](trio-comparison-20261118.json)。这是人工计划读取，不是 Token、实际模型选路、延迟或宿主 usage。普通 OFD 读取两侧均按入口自包含计量；需省略附属文字、修改预算、调查 partial 等任务必须追加对应参考，不套用普通读取降幅。

- 高频普通读取、常见续读、基础创建与必要校验保留入口；WPS 对象/修订细节、XLSX 专项导航、OFD 文件交付按需加载。
