## 修正与限制

初跑发现 DOCX 新规则使入口超预算，随后压缩重复表述；旧字面契约检查要求的字体编辑、宿主结果与交付状态文字已恢复，没有禁用断言或提高预算。期间修改造成的快照/源码一致性失败已在源码冻结后重新验收。

通用 `tools/run_all_tests.py` 固定 `-S` 会屏蔽 TL 已声明组件，不适合作为 TL 最终验收命令；本轮分套件采用正确解释器和启动参数。仓库内维护 venv 也会被独立包的拒绝源码访问保护拦截，因此改用已存在的仓库外环境，而非放宽保护。

未验证 Linux 容器、Windows、真实 DeepAgents 模型轨迹/工具回传、Office 视觉或用户文档。Skill 文本不能强制宿主禁止侦察、去重加载或提供文件映射。日志中的重复加载/挂载输出不足以证明 XLSX 解析器失败，本轮是执行说明防歧义与回归防退化，不声称生产故障已实测消失。
