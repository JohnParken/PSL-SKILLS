# 最小必要运行检查

2026-11-14 当前源码说明。此轮优化所有 12 个 Skill 的任务分流，不修改解析器、归档或安全文件操作实现。

| 类型 | 适用范围 | 处理 |
| --- | --- | --- |
| 纯指导 | bank-writing、document-navigation | 素材与入口可读即推进，不执行探针或环境命令；按需交接 |
| 读取/可选写出 | docx、tl-docx、xlsx、et、ofd、pptx、wps、table-workflow | 指定最小读取自检，附件仅定位任务顶层；生成、编辑、导出、缓存或实际临时写入才核对写入能力 |
| 有副作用生命周期 | artifact-lifecycle | 归档/登记/清理继续写入自检；纯读取不调用 |
| 仓库维护 | skill-development-standards | 只读检查不建写探针；目标是明确仓库位置，不限业务附件顶层 |

DOCX 报告分页可按既有契约尝试受控缓存，缓存不可写时仍退回无状态续读，不把缓存失败升级为读取失败。TL 缓存为显式选择。因此“仅读不建写探针”不等于承诺所有 stdout 读取永不使用缓存；不新增强制写入门槛。

不主动输出全量挂载表、环境变量或递归系统目录；根挂载的只读属性不代表任务挂载。使用已给出的入口路径和任务目录，实际自检和访问失败才触发对应的有界诊断。不同路径空间仅用宿主提供的映射，不猜测。继续保留防越界、原件保护、安全解析、状态与完整性核对。

检查器的结构通过不证明模型未调用其他工具。本轮未修改 DeepAgents 宿主，无法由 Skill 强制禁止侦察、重复加载或保证工具回传；生产日志里的重复加载和挂载输出也不足以证明解析失败。真实容器、模型执行轨迹、Office视觉和用户附件验收须分别记录。
