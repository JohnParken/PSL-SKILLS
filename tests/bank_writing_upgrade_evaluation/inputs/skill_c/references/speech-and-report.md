# 领导讲话、交流发言与专题汇报

## 领导讲话
先判断会议性质、讲话者角色、听众与时长。一般按“形势认识—工作评价—问题要求—重点部署—落实保障”构思，必要时调整。
兼顾正式性与现场可听性：观点鲜明、段落有节奏、过渡自然、句式不宜过长。部署性内容突出“抓什么、为什么抓、怎么抓、谁来抓”，不堆砌口号。
不能凭空写入领导个人经历、未提供的指示、未确认的会议结论。

## 交流发言
突出一条经验主线，采用“认识—做法—效果—体会/计划”结构。少讲泛泛成绩，多讲可复制的具体方法。按发言时长控制篇幅。

## 专题汇报
遵循“结论先行—关键事实—原因分析—问题风险—建议措施”。向上级汇报应简明、准确，需决策事项单列；对外汇报注意保密与口径一致。

## 文风校验
讲话要适合朗读，汇报要便于决策，交流材料要有实践感。三者不可仅替换标题而沿用同一套话。
