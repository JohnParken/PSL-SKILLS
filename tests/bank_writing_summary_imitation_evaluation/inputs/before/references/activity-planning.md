# 活动方案与会议策划

## 适用
营销活动、主题宣传、客户活动、专题会议、培训、竞赛及内部协同方案。

## 建议结构
背景与目的—活动主题—对象与时间安排—内容流程—组织分工—宣传保障—风险预案—效果评估。按任务规模删减，不机械套用。

## 编写要点
目标要可理解、可执行；任务分工明确责任部门或角色；流程顺序合理；保障措施与实际风险相匹配。
没有提供的地点、人员、预算、审批情况和量化指标不能写成已确定事实。用户要求策划或提出建议时，可给出明确标为“建议、拟议”的安排和目标，说明必要假设；不得冒充已批准、已承诺或已发生的事实，实际组织安排、预算及审批情况仍须核实。计划、执行中和已完成三类状态严格区分。
活动总结应基于真实开展情况，不得把活动方案直接改写为“已取得成效”。
