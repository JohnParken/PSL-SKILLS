# XLSX 真实业务文件测试资料

本目录是仓库维护测试资料，不随 XLSX Skill 分发。包含 2026-11-03 从政府及监管机构官网取得的 5 份原始工作簿、来源与 SHA-256 清单、独立计算验证脚本及两次历史执行证据。

从仓库根目录执行，使用 Python 3.9 及以上版本，仅依赖标准库：

```console
python3 -I -S -B skills/xlsx/scripts/stdlib_xlsx.py check
python3 -I -S -B tests/xlsx_real_business_20261103/verify_real_business.py
```

第一条命令须退出 0 且返回 `status: ready`。第二条命令退出 0 表示断言通过，完整 JSON 输出到 stdout；不会联网、启动 Office 或修改原始文件。不加 `-O` 或 `-OO`，以免禁用断言。默认单元测试发现命令不会自动运行本目录，需显式执行上述脚本。

Denham 对账表的下载文件名写 March 2020，但文件内业务日期为 2018/19；验证以文件内容为准。Ofgem 草案用于真实监管业务，不应当作经过审计的公司账目。

验证范围：

- 三份地方议会文件中共 30 个已计算原始公式，与独立 XML 读取及 `Fraction` 有理数计算结果核对。
- 天然气模型中 5 个原始 `SUMPRODUCT` 公式及其跨表依赖，单独与独立加权求和核对；这不代表整本模型通过。
- 9 个新增测试公式在原始银行交易明细上验证 `SUMIF`、`SUMIFS`、`COUNTIF`、`COUNTIFS` 和 `ROUND`，不冒充原文件中的公式。
- 核对 7 个银行业务总额及 28 笔付款分组勾稽；对每份文件执行真实分析 CLI，检查整表失败不会被小区域选取绕过。
- 原文件 SHA-256 在执行前后核对；旧公式缓存只用于差异比较，不作为独立预期或计算输入。

以上是当前能力和已知限制的历史基线，不要求未来版本继续拒绝这些文件。新增公式支持时同步扩展独立预期和验证范围，不能只修改成功计数或把部分结果当作整表成功。

`sources.json` 保留发布页面、原始下载 URL、获取时间及原文件 SHA-256。工作簿保留发布者原始内容与权利信息，不修改数据、公式、缓存或文件内部元数据。`ownership.json` 记录本次资料路径；其中 `write_probe` 已清理，不是缺失的测试输入。

`results.json` 和 `results_py312.json` 分别是 macOS/Python 3.9.6 与 3.12.14 的历史证据，包括脚本指纹、公式结果、失败分类、CLI 状态和文件完整性。记录中的解释器/工作区绝对路径仅描述当时环境；重跑使用当前机器路径。脚本的 `--output` 模式采用独占创建，拒绝覆盖已有证据，日常重跑使用默认 stdout 模式。

当前证据不覆盖 Linux、Windows 或 Excel 实际重算；断言通过也不表示五份工作簿均可完整计算。
